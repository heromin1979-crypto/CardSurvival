# Phase 3 — 전투 완성도·재미 향상 계획

> **작성일:** 2026-07-14 · **기간:** 1.5~2주 (로드맵 "몬스터 패턴 개선" 슬롯 + 완성도 병행 트랙)
> **전제:** Phase 2 완료 (`bc13020`), n=1000 기준선 = `docs/analysis/COMBAT_SIM_REPORT.md`(하한선) / `COMBAT_SIM_REPORT_PARTY.md`(실플레이)
> **진단:** 뼈대(랭크·토큰·인텐트·스트레스)는 완성 — 부족한 것은 ①시스템이 서로를 소비하게 만드는 연결(재미) ②사운드·에셋·UI 마감(완성도). 근거: 시뮬 드라이버가 "첫 피해 스킬 반복"만으로 DL3 60~72% 달성 = 최적 플레이가 단조로움.

두 트랙은 독립적이라 병행 가능하다. **재미 트랙(F)** 은 수치가 흔들리므로 밸런스 확정(F6)을 마지막에 한 번만 수행하고, **완성도 트랙(C)** 은 언제든 착수 가능.

## 재미 트랙 (F) — "읽고 대응하는 순간"의 밀도

### F1. 적 텔레그래프-카운터 전면화 (3~4일)

**현황:** timedThreat 3종(bloater/screamer/charger)만 "카운트다운 읽기 → 대응" 루프가 있고, 일반 12종 중 9종은 스탯만 다른 근접/원거리 (`docs/analysis/MONSTER_PATTERNS.md`).

**작업:** `js/data/enemies.js` 일반 12종 각각에 "텔레그래프 → 유효 카운터 1개" 계약 부여. 인텐트는 `_decideNextIntent`(CombatAiTurns.js)가 이미 표시하므로 대응 수단 쪽을 설계:
- `zombie_brute` slam(30-45, 기절 50%): 예고 턴 추가 → 방어(block 토큰)/이동으로 회피·경감 가능하게
- `zombie_horde` 라운드 2회 공격: 전열 유지 시 타겟 분산, 전열 붕괴 시 집중 — 진형 유지의 이유 부여
- `zombie_acid` 후열 산성: 방치 턴수에 비례해 acid_burn 중첩 — 후열 우선 제거의 이유 부여
- `raider`/`raider_elite`: 사기(morale) 노출 — 위협/처치로 rout 유도 가능함을 보여주는 로그·표기
- 각 적의 카운터가 통하는지 시뮬 드라이버로 검증 불가(전략 없음) → 개별 단위테스트로 계약 고정

### F2. 위치 공격 — 진형을 부수는 적 (2일)

**현황:** 4랭크 + 인접 스왑(Phase 2)까지 이동 기반은 완성됐지만 **적이 아군 위치를 공격하지 않아 진형이 정적**. 위치 시너지(+5%p/×1.05)는 체감 불가 수준.

**작업:**
- `CombatRankedEffects._applyRankedEffect`의 `move` 이펙트를 적→아군 강제 이동(`forcedMove`)으로 확장 — `moveCombatant` 재사용, 넉백(랭크+1)/끌어오기(랭크-1)
- `zombie_charger` charge_strike에 넉백 1랭크 부여, 신규 또는 기존 적 1종에 끌어오기 부여
- 위치 시너지 수치 상향 검토(후열 원거리 +5%p → 체감선), 랭크 이탈 시 스킬 잠금이 UI에 드러나게
- 회귀: 강제 이동 후 진형 불변식(전열 최소 1) 테스트

### F3. 토큰·스태미나 이코노미 — 2턴 계획이 성립하는 스킬 (2~3일)

**현황:** 토큰 11종이 구현돼 있으나 플레이어가 능동적으로 만들 이유가 스킬에 얇음. 시뮬에서 스태미나 부족으로 행동이 바뀌는 런이 관찰되지 않음.

**작업:** `js/data/combatSkills.js`
- 직업마다 "셋업 → 페이오프" 스킬 쌍 최소 1개 (예: focus 적립 스킬 → 치명 확정 소비 스킬)
- 강스킬 스태미나 비용 상향으로 "기본공격으로 버티는 턴" 유발 — `gameBalance.js` 상수화
- 신규/변경 스킬은 `combat.skill.<id>` ko/en 로케일 등록 + `check-help-coverage.mjs` 통과

### F4. 약점 발견·표기 — 다회차 지식 축적 (1일)

`weaponAffinityMult`(1.5/0.5)가 무기 선택을 바꾸려면 보여야 한다. 첫 타격에서 "약점!" 로그 시 `GameState.flags.enemyWeaknessSeen[enemyId]`에 기록 → 이후 조우부터 인텐트 배지 옆 약점 아이콘 표시. 세이브 flags에 자연 포함(스키마 추가 필드 — `Object.assign` 병합으로 구세이브 호환).

### F5. 스트레스 임계 이벤트 + 도주의 전략화 (2일)

- 스트레스 임계(붕괴선) 도달 시 1회성 갈림 이벤트: 붕괴(디버프) vs 각오(버프) — 기존 `_applyStressWithFeedback` 단일 창구에 결선. 적 rout과 대칭.
- 도주를 "자원 계산으로서의 후퇴"로: 도주 성공률·비용(`combat.flee`) 재설계 — 이길 수 있지만 비용 때문에 물러나는 선택이 성립해야 함 (필러 4 Scarcity).

### F6. 밸런스 확정 (F1~F5 완료 후 일괄, 1~2일)

- Phase 2 이관분: 실플레이 DL5 58~94% → 40~60% (조우 구성·적 HP), 약탈자 2인조 무기 상성 스프레드(권총 14% vs 소총 66%), 3v2 장기전 템포(맨손 25라운드 — 제한적 AoE 1~2종 검토)
- 절차: `--n 100` 스팟 반복 → 확정 `--n 1000` × 2조건 리포트 커밋 + BASELINE 비교표 갱신
- 소음45 셀 기준 판정 (소음 0 셀은 정숙 보상이므로 목표 적용 제외)

## 완성도 트랙 (C) — 마감 품질

### C1. 전투 사운드 결선 (1일, 즉시 착수 가능)

**현황:** `CombatFxPlayer._playFx`가 `EventBus.emit('combatSfx', {kind, fx, crit, miss, killed})` 발행 중이나 구독자 없음. `SoundSystem.js`는 WebAudio 신스 톤 패턴으로 `combatEnd` 등을 이미 구독.

**작업:** `SoundSystem`에 `combatSfx` 구독 추가 — kind별 신스 사운드 6종(타격/치명/미스/처치/자폭/상태이상). 파일 에셋 불필요(기존 playTone/playNoise 패턴). 설정의 음량/음소거 존중.

### C2. 전투 에셋 생산 (에셋 파이프라인은 완비 — 생산이 병목)

- 적 스프라이트 시트 잔여 14종(33종 중 19종 완료), 플레이어 12조합 중 11종(doctor_f만 완료), 배경 씬 5종 — 생성 프롬프트/파일명/등록 절차는 `docs/analysis/COMBAT_ASSET_BRIEF.md`에 준비됨
- 등록 후 `tools/audit_combat_sprites.mjs` + `CombatSpriteSheetAssets.test.js`로 규격 검증
- 시트/컷아웃 폴백 혼재가 완성도 체감을 깎는 주범 — 최소한 일반 조우 등장 빈도 상위 적부터

### C3. 전투 UI 잔손 (1~2일)

- 토큰 표시: 텍스트 span → 아이콘+스택+툴팁 (`CombatUI._renderCombatant`의 `.combat-token`)
- 상태이상 잔여 턴 수 표기
- 스킬 카드 푸터 텍스트 클리핑 수정 (Phase 1 기준선 등록 이슈, `css/screens-combat.css`)
- 스킬 프리뷰에 대상 방어 감산 반영 여부 검토 (`previewRankedSkill` — 현재 원피해 범위만 표기)
- 신규 표기는 ko/en 동시 등록

### C4. 검증 게이트

- 전체 테스트 green + 신규 효과(강제 이동·임계 이벤트) 회귀 테스트
- `node js/data/validate.js` Errors 0 / `check-help-coverage.mjs` 통과 / i18n combat.* ko:en 패리티
- focused E2E + UI 기준선 스크린샷 갱신
- 최종 n=1000 × 2조건 시뮬 리포트 커밋
