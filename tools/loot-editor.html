🎲 District Loot Editor

카드 서바이벌의 25개 구 lootTable을 시각적으로 편집합니다.
가중치(weight), 수량(minQty/maxQty), 오염 확률(contamChance)을 즉시 재계산되는 표에서 수정합니다.

📁 서버 없이 (어디서나)

file://로 열어도 됩니다. 모든 브라우저 지원.
저장 시 districts.js가 다운로드되어 수동으로 교체합니다.

📦 js/data 폴더를 여기로 드래그하거나

🚀 localhost 모드 (직접 덮어쓰기)

Chrome/Edge/Brave + localhost 서빙 필요.
저장 시 원본 파일이 바로 덮어쓰기됩니다.

python -m http.server 8080 또는 npm run dev 실행 후
http://localhost:8080/tools/loot-editor.html 접속.
