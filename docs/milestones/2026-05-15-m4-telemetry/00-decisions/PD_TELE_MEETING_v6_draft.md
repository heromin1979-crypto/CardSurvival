## 2. 안건 1 — M4 트랙 정체성 정의

### 2.1 안건 정의

> M4 트랙이 검증할 "게임 본체 K1"의 정의와 범위를 어디까지 잡을 것인가.

### 2.2 PD 시각

M3는 시뮬 player AI 행동으로 K1을 측정했다. 그러나 실제 player는:

1. 자유 행동 (시뮬보다 비효율 가능 / 더 효율 가능)
2. 시뮬 모사되지 않은 기능 사용 (예: dismantle, sketch_notebook, sublocation 탐색)
3. 학습 곡선 (첫 플레이 vs 5회차)
4. 직업별 플레이 패턴 (chef 플레이어가 시뮬 chef AI와 다른 의사결정)

**M4 트랙은 시뮬과 게임 본체의 격차 측정 트랙이다.** 격차가 작으면 시뮬 KPI 마지노선 신뢰. 격차가 크면 시뮬 보강 또는 게임 본체 보강.

### 2.3 트랙 정체성 후보

| 후보 | 정의 | 트레이드오프 |
|------|------|-------------|
| **A. 시뮬-본체 격차 측정 트랙** | drift.mjs leaf hash + 텔레메트리로 시뮬과 본체의 K1 차이를 측정 | 측정 인프라 중심 / 검증 지향 |
| B. 게임 본체 K1 직접 측정 트랙 | 시뮬 무관하게 본체 K1 자체를 측정·튜닝 | 시뮬 분리 / M3 산출물 재활용도 낮음 |
| C. 직업별 본체 학습곡선 트랙 | 1회차 vs N회차 본체 K1 비교, 학습 곡선 측정 | 사용자 데이터 필요 / 단기 측정 불가 |
| D. 혼합 트랙 | A + 일부 C | 범위 모호, 마감 정의 어려움 |

### 2.4 PD 권고

**후보 A 채택 권고.** 이유:
- §15 단정 ("M4+ 텔레메트리 트랙으로 분리")의 자연스러운 후속
- 시뮬 R11-1 완전 해소 단언의 신뢰도 검증이 본질
- drift.mjs leaf hash 컬럼 (협의서 v4 §13.6 단정) 동반 권고와 정합

## 3. 안건 2 — 신규 페르소나 영역 정의

### 3.1 안건 정의

> 텔레메트리 트랙을 누가 책임지는가. 신규 페르소나 신설 vs 기존 페르소나 확장.

### 3.2 옵션 후보

| 옵션 | 책임자 | 확장 범위 | 트레이드오프 |
|------|--------|-----------|-------------|
| **α. 텔레메트리 PD 신설** | 신규 페르소나 (Analytics/Telemetry PD) | 데이터 수집·분석·KPI 단정 전권 | 신규 페르소나 정의 작업 필요 |
| β. 시스템 백승호 확장 | 시스템 백승호 | 시뮬 로직 + 본체 텔레메트리 수집 | 백승호 작업량 가중 |
| γ. 밸런스 권지나 확장 | 밸런스 권지나 | baseline 측정 + 본체 측정 통합 | 권지나 시각이 시뮬 편향, 본체 측정 객관성 우려 |
| δ. PD 김재훈 직속 | PD 김재훈 | PD가 직접 측정·단정 | 협의·우선순위 작업과 충돌 |

### 3.3 PD 권고

**옵션 α 또는 β.** 결정 기준:
- 신규 텔레메트리 페르소나 정의 부담 수용 가능 → α
- 페르소나 추가 부담 회피 + 시뮬 통합 가치 → β

**현 시점 권고: 옵션 β (시스템 백승호 확장).** 이유:
- 시뮬 로직 책임자가 본체 텔레메트리 수집 채널도 책임지면 시뮬-본체 격차 측정 정합도 ↑
- 신규 페르소나 정의 작업 회피 (M4 진입 가속)
- 백승호의 시뮬 정합 5곳 등록 룰 (협의서 v5 §16.3) 노하우 재활용

### 4.2 KPI 정의 후보 (안건 1 후보 A 가정)

| KPI | 정의 | 마지노선 | 측정 시점 |
|-----|------|---------|----------|
| **본체 K1** | 실제 player 100일 생존율 (직업별) | 시뮬 K1 ± 10%p | 베타 테스트 N회차 |

| **시뮬-본체 격차 K_sim_drift** | 본체 K1 - 시뮬 K1 절댓값 (직업별) | ≤ 10%p | 텔레메트리 N회차 누적 |
| **drift.mjs leaf hash** | game data leaf 값 hash 컬럼 추가 | M3 v3~v14 12연속 fingerprint 유지 | 매 baseline 측정 |
| **본체 KPI Δ** | 본체 K1 / K3가 시뮬과 같은 추세인가 | ↑ 추세 일치 | N회차 비교 |
