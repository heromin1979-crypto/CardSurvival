# 캐릭터 문체 규칙

> 엔딩·퀘스트 서술문을 쓸 때 지키는 어휘·시선 규칙
> 근거: `docs/story/STORY_*.md` 6편에 이미 쓰인 문장에서 추출했다. 새로 지어낸 것이 아니다.

---

## 왜 필요한가

승리 엔딩 34개가 예외 없이 정확히 5줄이고, 그중 7개가 `100일.`이라는 같은 단어로 시작한다.
여섯 직업의 결말을 나란히 놓으면 **누가 말하는지 구분되지 않는다.**

산문 정사(`STORY_*.md`)에는 목소리가 이미 갈라져 있다. 정대한은 세상이 무너진 날 계산을 했고,
윤재혁의 하루는 칼끝에서 시작해 칼끝에서 끝났다. 그 차이가 게임 안 텍스트로 넘어오지 않았을 뿐이다.

이 문서는 그 차이를 규칙으로 고정한다.

---

## 공통 규칙

1. **결말의 무게를 길이로 표현한다.** 폴백·마일스톤 3~4줄, 정규 분기 엔딩 5~6줄,
   9단계를 밟은 종착 엔딩 7~8줄. `EndingSystem`은 배열 길이를 그대로 렌더하므로 코드 변경이 없다.
2. **첫 줄에 날짜를 쓰지 않는다.** `D+100`·`100일.`은 `subtitle`로 보낸다.
   첫 줄은 그 결말에만 있는 이미지로 연다.
3. **마지막 줄은 그 인물의 언어로 닫는다.** 서술자가 요약하지 않는다.
   `엔지니어의 재건.` 같은 마무리는 인물이 아니라 기획서의 목소리다.
4. **감정을 명명하지 않는다.** "기뻤다"가 아니라 기쁨이 드러나는 동작을 쓴다.
   최형식은 웃는 대신 커피를 한 모금 마신다.
5. **직업 어휘를 최소 두 번 쓴다.** 아래 각 인물의 *렌즈* 항목이 그 어휘다.

## 이지수 — 응급의학과 전문의

| | |
|---|---|
| **렌즈** | 손. 처치의 순서. 기록 |
| **어휘** | 봉합사·압박·처방·투여·병상 회전율·프로토콜 |
| **문장** | 짧은 절을 쉼표로 잇는다. 동작을 순서대로 나열한다 |
| **반복 모티프** | 메모지에 적는 습관. `치료법 확인.` |
| **금지** | 영웅적 수식. 그녀는 자기 공을 말하지 않는다 |

> 봉합사를 묶고, 압박을 풀고, 다시 묶었다.
> 살릴 수 있는 사람은 살린다.

기준선은 **"끝냈는가, 아니면 멈추지 않는 것을 세웠는가"** 다. 네 결말이 이 축 위에서 갈린다.

## 강민준 — 특수전 부사관

| | |
|---|---|
| **렌즈** | 신호. 좌표. 주파수 |
| **어휘** | 송출·수신·호출부호·집결·경계 |
| **문장** | 사실을 먼저 놓고 판단을 뒤에 붙인다. 군더더기가 없다 |
| **반복 모티프** | 박상현에게 말 걸기 (`박상현, 들었냐.`) |
| **금지** | 자기 연민. 그는 임무로 감정을 대신한다 |

> 신호란, 누군가 받아야만 의미가 있는 법이다.

## 최형식 — 전 건설회사 대표, 노숙인

| | |
|---|---|
| **렌즈** | 회계. 잃은 것과 남은 것 |

## 적용 체크리스트

엔딩 서술문을 쓰거나 고칠 때:

- [ ] 첫 줄이 날짜로 시작하지 않는다
- [ ] 직업 어휘가 두 번 이상 나온다
- [ ] 마지막 줄이 서술자가 아니라 인물의 목소리다
- [ ] 같은 인물의 다른 분기와 겹치는 문장이 없다
- [ ] 길이가 결말의 무게에 맞다
- [ ] `char_*`(퀘스트 미진행) 엔딩이라면 **성취가 아니라 우연**의 톤이다
