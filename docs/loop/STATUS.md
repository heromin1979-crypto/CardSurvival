- [2026-09-07] **INBOX 3군 "장착 중 아이템을 목표처럼 강조한다" — 강조할 카드가 화면에 없다.**

  `unequip()` 이 다시 `placeCardInRow` 로 돌려놓는다. 그래서 장착 중인 아이템은 휴대 행에
