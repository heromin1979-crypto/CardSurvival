## 이번 라운드가 보는 것

`main-screen-v2.png` **하나뿐이다.** 나머지 6장은 다음 라운드 후보이며,
INBOX 에 항목으로 올라오기 전까지 작업하지 않는다.

`main-screen-v2.png` 는 `../main-screen-target.jpg` 의 개정판이다.
**둘이 다르면 v2 가 이긴다.** 원본은 비교용으로 남겨 둔다.

v2 에서 새로 생긴 것 둘:
- 우측 패널이 `동료` + `동료 상태`(사기 MORALE / 유대 BOND) 두 블록으로 나뉘었다
- 장소 카드에 모서리 배지가 붙었다 (좌상단 아이콘 1~2개, 우상단 아이콘 1개)

## 왜 나머지를 범위 밖으로 두는가

셋은 **UI 작업이 아니라 시스템 작업**이다. 그림만 따라 만들면 껍데기가 된다.

- `combat.png` — 3인 파티 + 적 3마리, 전위/중위/후위 위치, 공포(Fear) 스탯.
  현재 전투는 1대1이고 위치도 공포도 없다. 화면이 아니라 전투 시스템을 바꿔야 한다.
- `equipment-detailed.png` — 상단에 `전투 / 탐색 / 휴식` 프리셋 탭이 있다.
  장비 세트를 저장·전환하는 기능이 지금 없다.
- `quest-a.png` / `quest-b.png` — 보상 카드에 EXP·스킬 포인트·평판이 있다.
  경험치도 스킬 포인트도 평판도 현재 데이터에 없다.

`equipment-simple.png` 와 `dialogue.png` 는 비교적 UI 에 가깝다.
메인 화면 라운드가 끝나면 이 둘부터 여는 것을 권한다.
