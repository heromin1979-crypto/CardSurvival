## 처리할 것

### 1군 — 레이아웃 골격 (목표와 가장 큰 차이)

- [ ] [2026-09-06] **상단 중앙 HUD 칩을 만든다.**
  목표는 화면 최상단 중앙에 `Day 18 | 14:32 | -4°C` 가 떠 있다.
  현재는 좌측 사이드바 안에 Day/시각/온도가 흩어져 있다.
  `#game-header` 가 비어 있으니 여기에 넣는다 (`js/ui/HeaderBar.js`).
  검증: 캡처 상단 중앙에 칩이 보이고 보드 첫 행을 가리지 않는다.

- [ ] [2026-09-06] **좌측 사이드바를 목표 구조로 재편한다.**
  목표 순서: 지도 → Day/시각/계절/날씨/온도 → 상태 → 소음 수치 → 휴대 무게 → 퀘스트.
  현재 순서: 지도 → Day/TP → 계절/날씨/온도 → 캐릭터 → 스탯 5종 → 소음 → 무게 → 행동 메뉴.
  행동 메뉴(탐색·퀘스트·동료·제작·숙련도·휴식)를 어디로 둘지 함께 정한다 —
  목표 이미지엔 없지만 게임에 필요하다. 없애지 말고 자리를 정해라.
  검증: 캡처의 좌측 패널 섹션 순서가 목표와 같다.

### 2군 — 사이드바 정보 구조

- [ ] [2026-09-06] **우측에 `동료 상태` 블록을 덧붙인다.** (v2 레퍼런스에서 새로 생김)
  `main-screen-v2.png` 의 우측 컬럼은 두 블록이다 — 위쪽 `동료`(초상화·장비·스킬,
  이미 만들었다) 아래에 `동료 상태`가 따로 있다. 내용은 `사기 (MORALE)` 게이지와
  `유대 (BOND)` 게이지, 각각 아래에 한 줄 설명.
  수치는 기존 코드가 이미 아는 값을 쓴다. 새 스탯을 만들지 마라 —
  없으면 만들지 말고 "막힌 것"에 남긴다.
  동료가 없을 때 이 블록을 어떻게 보일지도 정한다.
  검증: 캡처에 두 블록이 보이고 우측 컬럼 180px 안에서 넘치지 않는다.

- [ ] [2026-09-06] **소음을 독립 블록으로 승격한다.**
  현재 `소음 0 (-1.0/TP)` 회색 한 줄. 목표는 `소음 수치 (NOISE METER)` 제목 +
  퍼센트 + 굵은 게이지 + 위험 시 빨간 경고문(`위험! 소음 발생`).
  임계값과 문구는 기존 코드가 이미 아는 값을 쓴다. 새로 정하지 않는다.
  검증: 소음이 낮을 때와 높을 때 캡처 2장을 비교한다.

- [ ] [2026-09-06] **휴대 무게를 독립 블록으로 승격한다.**
  현재 `3.0/32kg (9%)` 회색 한 줄. 목표는 `휴대 무게 (WEIGHT)` 제목 + `42.1 / 60kg` +
  게이지 + 상태 라벨(`정상`). 과적 상태의 색 변화도 함께 정한다.
  검증: 정상/과적 캡처 2장 비교.

- [ ] [2026-09-06] **퀘스트 체크리스트를 사이드바에 상시 노출한다.**
  목표는 `퀘스트 (QUESTS)` 아래 `☑ 북촌 탐색 (진행중)` 처럼 2~3줄이 늘 보인다.
  현재는 `퀘스트` 메뉴 버튼을 눌러야 나온다 (`js/ui/QuestPanel.js`).
  진행 중 상위 2~3개만 접어 보여주고, 전체는 기존 패널로 넘긴다.
  검증: 캡처에 진행 중 퀘스트가 보인다.

- [ ] [2026-09-06] **지도 영역을 키우고 목표의 밀도에 맞춘다.**
  현재 지도는 작고 청록 와이어프레임이다. 목표는 더 크고 종이 질감에
  마커가 여러 개 찍혀 있다. 질감 에셋이 없으면 크기와 마커 밀도만 맞춘다.
  검증: 캡처에서 지도가 사이드바 폭을 채운다.

### 3군 — 섹션·카드 정보

- [ ] [2026-09-06] **섹션 헤더를 목표 형식으로 바꾼다.**
  현재 `장소` / `바닥` / `휴 대`. 목표 `장소 (LOCATIONS)` / `바닥 (GROUND ITEMS)` /
  `휴대 (CARRIED INVENTORY)`.
  ※ 섹션 헤더는 3개뿐이라 하드코딩으로 가능하다. **카드 이름의 한/영 병기는 하지 마라** —
     `nameEn` 이 없어서 별도 라운드다 (SPEC 4절).
  또 `휴 대` 가운데 공백이 들어가 있다. 같이 고친다.
  검증: 캡처의 세 헤더가 목표와 같다.

- [ ] [2026-09-06] **장소 카드에 설명과 요구치를 넣는다.**
  목표 카드: 썸네일 → 이름 → 설명 2줄 → `Requirement: 12`.
  현재: 이름 → 썸네일 → `위험 +5%` / `1TP`.
  현재 표시 중인 위험도·TP를 없애지 말고 어디에 둘지 함께 정한다.
  검증: 장소 카드 8장이 같은 높이로 정렬되고 설명이 잘리지 않는다.

- [ ] [2026-09-06] **장소 카드에 모서리 배지를 넣는다.** (v2 레퍼런스에서 새로 생김)

  현재 카드는 상단에 `들어가기` / `내부` 텍스트 배지만 있다.
  무엇을 표시할지는 **기존 데이터가 이미 아는 것** 중에서 고른다 (날씨 영향·잠금·위험도 등).
  없는 정보를 만들지 마라.
  검증: 배지가 썸네일을 가리지 않고 카드 8장이 같은 높이를 유지한다.

- [ ] [2026-09-06] **휴대품 카드에 수량·내구도 바를 넣는다.**

  현재: 이름 + `×5` 배지 + 아트 + 무게. 내구도가 카드에 안 보인다.
  검증: 내구도 있는 아이템(붕대·메스)과 없는 아이템(통조림)이 둘 다 깨지지 않는다.

  `--accent-primary` 를 쓴다. 새 색을 만들지 않는다.
  검증: 장착/미장착 카드가 캡처에서 한눈에 구분된다.

- [ ] [2026-09-06] **빈 슬롯 플레이스홀더를 정리한다.**
  현재 빈 칸마다 `소지품` / `발견한 아이템` / `클릭하여 이동` 글자가 반복돼 시선을 끈다.
  목표는 훨씬 조용하다. 대비를 낮추거나 아이콘 한 개로 줄인다.
  검증: 캡처에서 채워진 카드가 빈 칸보다 확실히 먼저 읽힌다.
