- 이번 개편은 `js/core/GameState.js`·`js/persistence/SaveManager.js`를 변경하지 않음
  (`git diff wip-backup-2026-07-13..HEAD` — 두 파일 diff 없음). 세이브 스키마 무변경.
- `GameState.deserialize`는 combat/encounter 상태로 저장된 세이브를 'main'으로 강제 복원하므로
  전투 중 상태가 세이브를 통해 이월되지 않는다. 신규 전투 필드는 `Object.assign` 병합으로
  기본값 유지 → 구버전 세이브는 구조적으로 호환.
- 잔여 수동 확인: 실기기 구버전 세이브로 이어하기 → 전투 진입 1회 (빌드 exe 프로필에는
  기존 세이브가 없어 자동화 불가).
