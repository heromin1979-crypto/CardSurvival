# 25개 구 수급·탐색도 보상 재배치안

작성일: 2026-09-17. 작업5 적용일: 2026-09-20. 상태: 75행 원료 묶음·일반 드랍 7축·25구 발견 공급처 적용. 수량은 실제 소비 최소 단위와 대조한 초기값이며 24조건 전체 플레이 검증 전이다.

## 작업5 실제 적용과 제안 차이

- 아래 25×3 보상의 아이템·고정 수량은 모두 제안과 일치한다. [75행 대조표](progression-execution/task-5-regional-comparison.md)는 최종 데이터로 재생성하고 일치를 assert한다. 기존 milestone_30/60/100 ID와 version1은 유지해 청구 이력을 무효화하지 않는다.
- 100%의 이름뿐인 단서는 실제 반복 공급처로 연결했다. 기존 발견5개에 신규20개를 더했다. 겨울에도 가능한 창고·작업장 교환과 봄/여름/가을 약초 채집을 구분한다. 강서·금천·성동은 금속 회수/선별, 고위험 송파·종로는 전원·통신 재료 묶음으로 차별화한다.
- 기존 초기 공급6개·발견5개는 보존했다. 작업4 발전 소비를 반영해 용산·성동·은평에 탐사도 무관 연료 교환을 추가했다(고철4→연료1,2TP,재고2/72TP). 총 공급처34개다.
- 강남·동작·서대문 표면 약품을 천조각·알코올·약초로, 성동 정제금속을 숯으로, 영등포 코일·용산 칩을 기판으로, 동대문 큰천을 천조각으로 바꿨다. 동작 계절 약초를 추가했다. 기존 최초 방문 응급품·물/통조림·배터리·로프 및 위험 장소의 유한 완제품 회수는 유지한다.
- 지도와 현지역 공급창에 다음 묶음·용도·100% 공급 단서·거리/로비/세부장소 재고 차이를 표시한다. 100% 완료 뒤 탐사 보상은 반복 지급되지 않는다고 표시한다.
- 공급상태 없는 구세이브와 기존 version1 모두 100% 구의 새 발견권을 합친다. 기존 재고·청구·조사·물품은 보존하며 보상 물품을 소급하지 않는다.
- 작업3의 초기 장소 보장과 water_filter 제작 경로를 재사용하므로 작업5에서 초기 지급을 중복 추가하지 않았다. 최종 전체 캠페인 속도·겨울 장기 경제 판정은 작업6에 남긴다.

## 최초 제안 당시 판정 (작업3·5 이전 기록)

- `districts.js` 25개 구 모두 기본 증가량 5%, 보상 30/60/100%, 각 보상 3~5개다. 필요한 누적 증가 횟수는 6/12/20회다. 전투·이동·날씨가 있어 실제 행동 횟수나 소요일과 같지 않다.
- 종류·지급 시점은 확정이지만 수량은 `_advanceExploration()` → `rollQty()`에서 무작위다. 강서 로터 3~5개는 최종 조립 요구량 4개에 못 미치거나 넘는다. 부족 보완과 전 공정 생략을 같은 보상이 번갈아 만든다.
- 동작 100% 케블라, 광진 60% 약초 가루, 중구 100% 합금, 용산 100% 케블라는 대표 직업 동선과 제작 목적을 설명하기 어렵다.
- 관악 위험도 1의 회로 모듈과 구로 위험도 2의 같은 보상은 용산 위험도 3의 회로 모듈 보상과 수량이 같다. 위험을 감수할 유인이 보상 데이터에 충분히 구분되지 않는다.
- 강서의 항공 합금·로터, 영등포의 발전기 코어는 가공 체인을 크게 건너뛴다. 이것이 곧 헬기 엔딩 우회라는 뜻은 아니다. 최종 조립의 날짜·설비·숙련 게이트는 별도로 남는다.
- 랜드마크 로비 탐색은 지역 탐사도를 올리지 않는다. 세부장소는 첫 루팅 및 재고 감소가 적용된다. 로비는 `_generateLandmarkLoot()`에서 재고 비율을 전달하지 않는다. 세부장소를 뒤지는 활동과 % 목표가 분리돼 있고, 반복 로비 수급이 경제를 우회할 여지가 있다.
- 보상 만차는 `_placeLoot()`가 `pendingLoot`에 보관한다. 탐사도 증가가 단조롭다면 임계값 중복 지급도 막힌다. 이 두 장점은 유지한다.
- 100% 이후에도 구 일반 자원 재생과 탐색 보너스가 있다. 반복 보상이 전혀 없는 구조는 아니다. 다만 특정 부품/종자의 지속 공급과 지역의 장기 용도는 따로 설계해야 한다.

## 배치 원칙

1. 일반 구 탐색: 범용 생활 원료와 분해 가능한 잔해 중심. 붕대·소독약·진통제 등 완제품을 한 번에 전부 제거하지 않는다. 초반 비상 구호물자와 시작 보장을 먼저 마련한다.
2. 세부장소: 지역의 특화 원료, 회수 대상, 소량의 사용 가능한 완제품. 위험한 특정 장소의 완제품 발견은 보상으로 유지한다.
3. 30%: 당장 한 공정을 시작할 최소 재료. 60%: 관련 분야의 병목 보완. 100%: 특화 재료 묶음과 지속적인 공급처/프로젝트 단서. %는 후반 진행도나 숙련도와 동일하지 않다.
4. 지도에서 다음 보상과 용도를 미리 보여준다. 확정 보상은 고정 수량으로 지정한다. 임계값 도달 시 받지 않을 선택을 강요하지 않는다.
5. 표의 공급처 발견은 신규 구현이다. 기존 `explorationYields.items`에 장소 이름을 아이템처럼 끼워 넣지 않는다. 재고·재입고 주기·접근 조건·수령 이력으로 관리한다.
6. 표에 사용한 아이템 ID는 현행 아이템에 존재한다. 실제 수급량은 시작 보상·NPC 거래·분해·낚시·채집·퀘스트 보상까지 합쳐 조정한다.

## 일반 드랍 우선 수정

- 강남: bandage·antiseptic의 높은 가중치를 cloth_scrap·원료·잔해로 이동. 병원 첫 방문 구호품은 보존.
- 동작: bandage 반복 수급을 줄이고 cloth_scrap·herb 접근을 확보. 의사 시작 medical_station과 붕대 4개를 감안해 첫 환자를 원료 파밍에 묶지 않는다.
- 서대문: bandage·antiseptic·painkiller 위주 표면 드랍을 의료 잔해·기초 재료로 바꾸고, 사용 가능한 약품은 약제실로 집중.
- 성동: refined_metal 반복 표면 드랍 축소, 고철·제련용 투입재로 대체.
- 영등포: copper_coil을 wire·circuit_board 또는 회수 대상에 이전.
- 용산: microchip을 circuit_board 회수로 전환. 기판 추출로 칩과 구리선을 선택하는 공정을 살린다.
- 동대문: large_cloth 일반 드랍 축소, cloth·thread 가공 경로 유지.
- 물병·통조림·배터리·로프는 전량 제거하지 않는다. 도시의 즉시 사용 가능한 물품이자 비전문 직업의 생존 대안이다. 최종 비중은 아래 검증을 통과한 뒤 확정한다.

## 막힘 방지와 검증

- 소금: 현재 청사진 생산 경로 없음, 구 일반 드랍 없음, LANDMARK_DATA의 해당 전리품은 호텔 저장고에 집중. 다른 퀘스트/상인/아이템 분해 경로까지 합산 전 '획득 불가'로 판정하지 않는다. 중구 초반 확정 구호 묶음과 반복 시장 공급을 확보한 뒤 레시피 수요를 맞춘다.
- circuit_board: 고급 전자 제작의 출발 재료인데 확인한 랜드마크 드랍은 발전소·통신탑 세부장소에 집중. 용산·구로의 초기 회수 경로를 추가해야 고급 완제품 드랍을 줄일 수 있다.
- soil_bag: 구 일반 드랍이 없지만 gravel_pile(자갈 더미) 분해에서 50% 확률로 1개를 얻는다. 기존 텃밭 분해 회수도 있다. 최종 병합된 ITEMS의 weed_patch에는 흙 산출이 없으므로 초기 감사의 해당 예시는 정정한다. 확정 종자와 흙을 함께 지급하고, 환경물 분해의 확률 실패가 재배를 영구 차단하지 않도록 반복 대안을 둔다.
- water_filter: 청사진 생산 경로 없음. `charcoal_filter`와 다른 ID이며 자동 호환되지 않는다. 정수기 제작에는 회수 필터 확보 또는 실제 제작 레시피 추가가 필요하다.
- 직업별 초반 경로는 % 보상 20회 누적을 요구하지 않는다. 대화 단서·초기 지급·가까운 지정 장소로 첫 프로젝트를 시작한다.
- 30/60/100%는 유지하되 원료 최소 묶음은 10~15% 또는 초기 프로젝트 보상으로 보완할지 플레이테스트한다. 이미 지난 보상은 저장된 청구 이력으로 구분하고 재접속 중복 지급을 막는다.
- 6직업 × 봄/겨울 × 일반/불리한 난수 조건으로 첫 프로젝트와 첫 중간 설비까지 진행한다. 이동 TP, 제작 TP, 피로·수분, 원료 대기, 제작 단계 생략, 재방문 이유를 기록한다. 수치 조정 전에는 이 표를 최종 밸런스라고 부르지 않는다.
