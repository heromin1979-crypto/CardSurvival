# 캐릭터별 초반 인터랙션·동선 및 연출 보강 검토

작성일: 2026-09-21. **현황 점검·제안 문서이며 아래 신규 장면과 퀘스트는 미구현이다.** 이번 작업에서는 게임 소스를 수정하지 않았다.

실제 코드 기반으로 현재 동작과 제안을 구분했다. 캐릭터별 공통 경로 `shared.js`의 01~10번, 총60개 목표를 비교했다. 데이터상 D1~D21 구간으로, 실제 플레이 첫 30분이나 한 회차 노출 횟수를 뜻하지 않는다. 시작 처리·NPC 등장·조우·퀘스트 판정·연출 호출도 확인했다. [집계 원본](2026-09-21-early-interaction-audit.json).

## 1. 종합 판정

**시작 능력·지역·직업 프로젝트는 차별화되어 있지만, 초반에 플레이어가 경험하는 사건과 행동의 순서는 충분히 차별화되지 않았다.** 의사는 NPC 치료·간호사 협력이 실제 목표이고, 나머지는 수집→준비→프로젝트 중심이다. 이전 개편으로 제작·운영은 강화됐지만 인물 간 상호작용과 위험 대응이 그 공정 앞뒤에 충분히 연결되지 않았다.

| 캐릭터 | 시작 구 | 첫10목표 중 수집 | NPC 치료·의뢰 직접 목표 | 직업 프로젝트 | 주요 공백 |
|---|---|---:|---:|---:|---|
| 이지수 / 의사 | 동작 | 2 | 4 | 0 | 실제 처치와 이야기의 정확한 연결, 외부 수급·비전투 위기 |
| 강민준 / 군인 | 도봉 | 6 | 0 | 2 | 시작 위치와 용산 서사 불일치, 동료·정찰·호위 경험 |
| 박영철 / 소방관 | 은평 | 6 | 0 | 3 | 구조 상황·실제 부상자 도움, 시작 위치와 용산 서사 불일치 |
| 최형식 / 거리 생존 | 광진 | 4 | 0 | 4 | 인맥·협상의 인물화, 불·정수 목표의 실제 행동 판정 |
| 윤재혁 / 셰프 | 중구 | 5 | 0 | 3 | 초반 손님·동료·메뉴 결정, 조리 경험의 빠른 노출 |

수집은 `collect_item`과 `collect_item_type` 합계로 **30/60**이다. 60개 주 목표에 `kill_enemies`는0개다. 이는 전투가 없다는 의미가 아니다. 탐색에는 지역·계절·야간·소음 등의 영향을 받는 조우가 있고, 조우 화면에는 공통 전투/은신/도주, 군인 선제 제압, 병원 습격의 의사 대피 지휘가 있다. **직업의 목적을 가진 초반 위험 상황을 퀘스트가 안내하는 정도가 약하다**는 판단이다.

여섯 직업 모두 공통10단계가 D1·2·4·6·8·10·13·15·18·21이라는 같은 최소 날짜를 쓴다. `QuestSystem._checkMainQuestTriggers()`가 선행 완료와 날짜를 함께 검사하므로 준비가 빨라도 다음 직업 사건은 기다린다. 달력 전체를 없애기보다 초기 직업 체험은 행동 완료로 연결하고, 실제 시간 경과가 필요한 회복·비축·소문만 날짜를 유지하는 방향을 권한다.

## 2. 캐릭터별 현황과 보강안

### 이지수 — 사람을 살리고, 다음 치료를 준비하는 시작

**현재:** `_doctorEmergencyOpening()`의 치료/탈출 선택, 시작 NPC 박상훈·간호사, `mq_doctor_01` 실제 완치, `02` 간호사 개인의뢰, `03/05` 완치 목표가 있다. 동작 병원 기반→약초·의료 제작→D18 마포 방문이다. 병원 습격은 `er_unlocked` 조건과 D10부터의 스케줄을 쓰며 의사에게 대피 지휘 선택이 있다. 자동으로 정확히 D10에 반드시 발생하는 것은 아니다.

**부족한 부분:** `04` 제목은 환자 수액이지만 깨끗한 물품 보유3개, `10`은 자기 처방이지만 의료 제작1회가 주 판정이다. 설명의 치료 행위와 실행 조건이 다르다. `03` 완치2명 이후 `05` 완치1명은 동일 누적 완치 기록으로 충족될 수 있어, 제목상의 새 환자를 반드시 만나는 목표가 아니다. 처음 부상 군인은 시작 붕대로 치료하는 안내이므로 복합 의료 제작의 깊이와 구분해야 한다.

**권장 흐름:** 응급실에서 환자 상태 확인 → 실제 응급처치 → 간호사와 소모품 부족 논의 → 인근 창고/외부 약품 수급 중 위험 회피 → 회복 확인과 환자의 답례. 수액·자기 처방은 실제 사용/치료 단계로 판정하거나 제목·대사를 현재 판정에 맞춘다. 새 환자 사건은 해당 환자 ID나 사건 이후 치료 기록을 요구한다.

**초반 선택:** 간호사에게 처치를 맡기고 재료를 찾을지, 환자를 안정시킨 뒤 움직일지. 전투에서는 약품 회수와 부상자 대피 중 우선순위를 선택한다. 새 환자나 위기를 무한 반복시키지 않고 첫 사례를 한정한다.

### 강민준 — 정찰하고, 사람과 보급을 안전하게 이동시키는 시작

**현재:** 도봉 시작/개 카드 제공. 첫 퀘스트 서사는 용산 무기고인데 목표는 나이프 보유1개이며 시작 지급에 이미 나이프가 있다. D2 방어선은 구조물 아무1개 제작, D6 용산 무전 복원, D15 종로 이동으로 이어진다. 사람 동료인 탈영병은 용산 D30 등장이다.

**부족한 부분:** 도봉에서 시작해 용산 기지 안에 있다는 문장을 읽는다. `02`는 바리케이드를 설치하지 않아도 구조물 제작으로 완료될 수 있다. 전투 수치는 특화되어도 무엇을 지키거나 누구를 데려오기 위해 싸우는지는 첫10목표에서 약하다. 개는 시작 등록 결함도 있다(5절).

**권장 흐름:** 도봉 퇴각 집결지 → 군견 상태 확인·식량 분배 → 짧은 정찰로 안전/위험 통로 확인 → 고립 생존자와 무전 접촉 → 용산 도착 후 통신 복원. 도봉 시작을 유지한다면 용산은 도착 목적지로 설명하고, 용산 무기고 출발을 유지하려면 시작 지역과 수급을 함께 재설계해야 한다. 두 위치 설정을 혼용하지 않는다.

**초반 선택:** 정면 제압 / 군견 경고를 따라 우회 / 보급을 일부 포기하고 호위. 통로 확보는 적 처치 외에도 안전한 우회·구조 대상 도착으로 인정한다. 첫 정찰 전투는 제한된 위험과 후퇴 경로가 있는 사건으로 구성한다.

### 박영철 — 위험을 읽고, 사람을 꺼내고, 거처를 안전하게 만드는 시작

**현재:** 은평 시작이지만 `01`은 용산 출동 서사, `02/04/07` 프로젝트는 용산이다. `03`은 이재훈 추모와 의료품 보유3개, `06`은 부상자 치료라는 제목과 붕대 보유5개가 연결돼 있다. 이후 서대문 방문으로 이동한다.

**부족한 부분:** 실제 구조 대상과 접근 방법을 결정하지 않아도 대부분 진행한다. 가족이 있는 은평에서 출발해 용산으로 돌아간 뒤 다시 가족을 향하는 동선의 이유가 드러나지 않는다. 이재훈의 죽음이 수집 퀘스트 문장 안에 들어가 감정적 사건으로 경험되기 어렵다.

**권장 흐름:** 현재 은평 시작을 유지한다면 ‘용산 사건 이후 귀환했지만 가족 거처가 비어 있다’는 상황을 명확히 한다 → 잔해 속 생존자 발견 → 구조 상태 확인 → 지렛대 진입/로프 우회 중 준비 → 실제 구조·응급처치 → 용산의 장비나 집결 정보가 필요하다는 단서를 받아 출동한다. 기존 이재훈의 사망 설정은 보존하며, 생존 가능한 신규 구조 대상은 별도 인물로 표시한다.

**초반 선택:** 진입로 보강에 재료를 쓸지, 우회에 시간·피로를 쓸지. 전투는 좀비 처치량보다 ‘통로 확보→사람 이동→출구 봉쇄’를 목적에 둔다. 무작정 빨리 들어가는 선택을 일방적인 정답으로 만들지 않는다.

### 최형식 — 버려진 것을 살리고, 정보와 신용으로 살아가는 시작

**현재:** 광진에서 식량→불→회수 공정→정수→한강 낚시 거점→교환·창고→송파 도하로 이어진다. 생활·회수 흐름은 비교적 뚜렷하다. 그러나 낚시꾼 집단 만남은 장소 방문 완료 문장이고 `homeless_trade`는 프로젝트 교환이다. 전 건설 동료는 양천 D10로 주 동선에서 멀다.

**부족한 부분:** ‘거리의 인맥’이 실제 대화 선택으로 드러나지 않는다. `02`의 불은 구조물 아무1개, `04`의 정수는 깨끗한 물품 보유로 판정한다. 불을 사용하거나 직접 정수하는 경험을 필수로 만들지 못한다.

**권장 흐름:** 다리 아래 잠자리 정리 → 실제 불·물 마련 → 낚시꾼 접촉 → 회수품 선별 → 물품/노동/정보 교환 → 다음 공급 약속을 통해 송파 통행 준비. 낚시꾼은 기존 정식 NPC가 있는 것처럼 취급하지 말고 신규 집단 대화 대상으로 정의한다. 양천 동료 재회는 선택 원정으로 남기고 초반 필수 협상은 광진에서 경험시킨다.

**초반 선택:** 당장 유리한 교환 / 다음 방문 공급 약속 / 짐을 줄여 안전한 골목으로 이동. 위험에서는 싸움보다 소리 유인·우회·짐 포기와 물자 회수의 손익을 보여준다. 도주 능력은 숫자 보너스와 별개로 결과 대사와 이동 경로에서 확인시킨다.

### 윤재혁 — 재료 목록보다 먹일 사람을 먼저 만나는 시작

**현재:** 중구 식재료·구조물·소금·식수·약초 준비 이후 D10 첫 배식, D13 저장 작업장이다. 시작 완성 음식으로 첫 배식도 가능하다. 주방 보조는 D25, 부주방장은 D35에 등장하므로 첫 배식 시점과 협력 NPC가 분리된다.

**부족한 부분:** 누가 어떤 상태로 음식을 기다리는지보다 재료 목록이 먼저 나온다. 임시 조리대는 구조물 아무1개 제작이고, 처음부터 직접 요리해야 하는 흐름이 보장되지 않는다. 보존·위생·소모품·인원수 판단이 초반 목표에 약하다.

**권장 흐름:** 시장에서 식사가 필요한 생존자 접촉 → 인원·상태 질문 → 현재 재료로 메뉴 선택 → 물·열원 준비 → 직접 조리·제공 → 반응을 듣고 다음 공급처 소개. 첫 전문 행동은 D10까지 늦추지 말고 초기 몇 행동 안에 체험시키고, 기존 첫 배식 프로젝트는 정기 운영으로 발전시킨다.

**초반 선택:** 적은 양의 진한 회복식 / 더 많은 사람에게 나눌 기본식 / 일부 보존. 모든 메뉴는 실제 재료와 조리 조건을 검사한다. 시장 수급 위험에는 위험한 창고 회수와 안전한 교환의 대안을 둔다. 기존 동료의 초기 접촉을 앞당겨도 영입·희귀 선물·고급 의뢰까지 같이 앞당기지는 않는다.

### 정대한 — 재료를 모으는 사람이 아니라 고장을 해결하는 사람으로 시작

**현재:** 용산 작업대 공정 이후 전자부품·철사·천·목재·로프를 차례로 수집하고 D15 발전 공정, D18 성동 방문으로 이어진다. 정비사 NPC는 구로 D25다. D13 메모·D18 성수 방문에는 회상이 연결돼 있다.

**부족한 부분:** 첫10개 중7개가 수집이다. ‘아버지의 메모’가 로프2개 보유로 완료돼 사건과 조작이 어긋난다. 사용자가 없는 제작은 부품 요구표로 느껴지기 쉽다. 이전 수급 시험에서도 분해와 인접 지역 회수 경로를 알 때 첫 작업 비용이 크게 줄었다.

**권장 흐름:** 전원이 끊긴 셔터/급수기 등 구체적 고장 발견 → 진단으로 필요한 계통 확인 → 통나무·잔해 분해와 부품 교환 안내 → 임시 우회 배선/안정 수리 선택 → 실제 전원 투입 → 문이 열리거나 물이 나오는 결과 → 수리 의뢰인의 다음 단서. 정비사와의 초반 접촉은 무전이나 작업 메모로 시작하고, 구로 대면과 영입은 별도 단계로 둔다.

**초반 선택:** 빨리 작동하지만 재정비가 필요한 임시 수리 / 재료를 더 쓰는 안정 수리. 소음이 적을 불러올 수 있음을 작업 전에 알리고 조용한 수동 작업과 전동 작업을 구분한다. 고장 진단 없이 부품만 넣어 같은 결과를 받는 구조는 피한다.

## 3. 연출 현황: 기반은 있고, 초반 행동의 결과가 약하다

- `cinematicScenes.js`: **48개 정의, 이미지 경로31개**. 이 중 `cin_char_chef`의 `assets/images/cinematic/char_chef_final.webp`는 실제 파일이 없다. 나머지 이미지 참조30개는 파일 존재를 확인했다. 이는 화면에서의 미적 완성도나 모든 경로 재생 검증과는 다르다.
- 여섯 직업의 주요 공통 분기 연출은 모두10번 목표(D21 최소)에 연결된다. 초반 추가 퀘스트 회상은 기계공07·09번이다. 의사만 시작 전용 `openingScene` 경로가 있다.
- `CinematicScene._showNow()`는 배경 이미지/그라디언트, 제목, 순차 페이드 문장 중심이다. 현재 사건의 대상·진행·결과를 장면 안에서 움직여 보여주는 연출은 별도 보강해야 한다.
- 전투에는 `CombatFxPlayer`의 공격·피격 모션과 `combatSfx`, 일반 제작 성공/실패 및 경고 합성 효과음이 있다. 분해에도 `dismantleFx`가 호출된다. 모두 없다고 평가하지 않는다.
- `BGMSystem`은 `theme_remix.mp3` 한 곡 루프다. 지역·직업 사건·안전/위기 변화에 따라 트랙을 전환하는 구성은 이 시스템에 없다.
- 퀘스트 장면은 실제 화자 참조가 없으면 ‘생존 기록’으로 표시된다. 이야기의 상대가 없는 프로젝트 장면에 NPC 초상화만 임의로 붙이지 않는다.

## 4. 연출 보강 목록과 우선순위

우선순위 A는 초반 체감에 직접 영향을 주는 내용, B는 반복 플레이와 상태 전달, C는 주요 전환점의 감정 표현이다. 시간은 제작 제안이며 확정값이 아니다.

| 순위 | 넣을 위치 | 구체적 연출 | 플레이와의 연결 |
|---|---|---|---|
| A | 캐릭터 시작 | 의사 신음·멈춘 조명, 군인 군견 경고·끊긴 무전, 소방관 비어 있는 거처와 출동 흔적, 거리 생존 강바람·젖은 침구, 셰프 빈 그릇, 기계공 멈춘 설비 | 20~40초 안팎의 건너뛰기 가능한 도입 뒤 바로 첫 선택. 과거 설명 전체를 읽히지 않음 |
| A | 첫 NPC 접촉 | 상대가 먼저 부족한 것을 말하고 도구·상처·빈 그릇 등 대상 한 곳을 강조 | 질문→행동 결정→실제 목표 표시. 인사와 퀘스트 수락 팝업을 중복하지 않음 |
| A | 첫 전문 행동 성공 | 환자 호흡 안정, 무전 잡음 뒤 응답, 구조 출구 개방, 불 점화, 첫 그릇 전달, 모터 회전 | 실제 완료 이벤트 이후2~5초. 보유나 버튼 클릭만으로 성공 장면을 선행 재생하지 않음 |
| A | 첫 위험 조우 | 발소리/그림자/흔들리는 문 등 징후→관찰 가능한 위험→대응 선택 | 공격/우회/후퇴 결과 차이를 안내. 보이지 않던 불이익을 연출 뒤 임의 부과하지 않음 |
| A | 주요 설치·거점 변화 | 어두운 작업장이 켜짐, 의료 침상 채워짐, 급식 그릇이 놓임, 출입구에 방벽이 생김 | 저장된 설비·재고 상태에 따른 전후 모습. 가동 중단 시에도 일관되게 반영 |
| A | 초반 길 찾기 | 지도에 ‘현재 위치→다음 단서→부족 재료 대안’ 한 경로씩 표시 | 용산으로 가는 이유와 회수 대안을 전달. 지도 전체 아이콘을 동시에 번쩍이지 않음 |
| B | 첫 밤·휴식 | 주변 소리 감소, 불빛 범위 변화, 동료의 한마디와 경계 분담 | 기존 `nightStarted`/야간 경비 활용. 매일 강제 컷신 대신 상태 변화 때만 대사 |
| B | 부족·실패·회복 | 발전기 헛돎, 젖은 불쏘시개, 손 떨림 등 실패 이유를 짧게 전달 | 재료 반환/소비·숙련·대체 행동 안내와 일치. 실패 연출로 재시도를 늦추지 않음 |
| B | 위험한 이동·첫 지역 진입 | 멀어지는 이전 거점, 랜드마크 실루엣, 오염 구역 소리·색 변화 | 실제 위험 정보와 대응 준비를 먼저 보여주고 처음 또는 큰 변화 때만 강조 |

| B | 소리의 상황 변화 | 병원/강변/시장/작업장 환경음, 위기 시 음악 축소, 회복 시 안정된 소리 | 효과음 우선순위·볼륨·무음 설정, 자막/시각 신호를 함께 지원 |
| C | 기억·상실·분기 | 이재훈의 장비, 군번줄, 아버지 메모, 과거 주방 도구 등 물건 중심의 짧은 회상 | 실제 물건 발견·확인 행동에 붙임. 로프 수집으로 메모 회상이 발동하는 연결부터 정리 |
| C | 후반 성과·엔딩 | 초반과 같은 구도를 되찾아 치료소·구조망·주방·공장의 변화를 보여줌 | 플레이어가 완성한 시설·선택과 일치. 마지막에 새로운 설정을 갑자기 추가하지 않음 |

첨부된 좌측 인물/우측 선택 구조와 기존 앰버·블루 디자인을 유지한다. 긴 영상보다 기존 장면에 대상 강조·환경음·짧은 상태 변화·후속 반응을 더하는 방식이 유지보수와 반복 플레이에 적합하다. 화면 흔들림·번쩍임은 줄이기 설정을 제공하고, 필수 정보는 효과를 꺼도 읽을 수 있어야 한다.

## 5. 콘텐츠 추가 전에 보강할 실제 연결 문제

1. **군인의 개가 시작 동료로 등록되지 않고 카드가 중복된다.** `CharCreate._startGame()`의 `startingCompanion`은 카드만 만든다. 이후 `NPCSystem._checkSpawns()`가 개를 다시 스폰한다. 실제 시작 함수를 NPCSystem과 연결한 Node 재현에서 개 카드2개, `companions=[]`, `isCompanion=false`였다. 단일 생성·상태·동료 등록 경로로 정리하고, 의도한 것이 ‘영입 전 첫 만남’이라면 데이터명과 안내를 그에 맞춘다. 이번 점검에서 수정하지 않았다.
2. **직업 전용 NPC 조건이 스폰에서 적용되지 않는다.** 전 건설 동료는 `spawnCondition.requiredCharacter='homeless'`지만 `_checkSpawns()`는 날짜·지역만 검사한다. 기계공/D10/양천으로 실행했을 때도 등장했다. 조건 평가를 스폰 공식 경로에 연결해야 캐릭터별 인연을 구분할 수 있다.
3. **서사 이벤트 이름 불일치.** 정비사 서사·기억은 `craftCompleted`, 탐색 기억·딜레마는 `exploreCompleted`를 구독한다. 현재 소스에서 해당 발행은 찾지 못했고 실제 제작은 `craftComplete`다. 이전 대화 계획의 미완료 항목으로 남아 있다. 추가 문안을 쓰기 전에 발동·누적 횟수·동행 기간 계약을 복구한다.
4. **셰프 엔딩 이미지 경로 누락.** 위 파일 참조를 실제 자산에 맞추거나 해당 자산을 제작하고, 이미지 없는 상태에서도 내용을 읽을 수 있는지 검사한다.
5. **제목·대사와 목표 판정의 불일치.** 첫 불/조리대/방어선은 구조물 카테고리, 부상자 치료는 붕대 보유, 메모는 로프 보유 등의 사례다. 목표를 구체화할 때 기존 세이브의 완료 이력을 취소하지 않고 진행 중 목표의 이전 정책을 정한다.

군인·소방관 시작 위치 문제는 단순 오류 수정으로 시작 구를 바꾸지 않는다. 시작 물자·NPC·동선·위험도에 함께 영향을 주므로 **현재 시작 구 유지 + 이동 이유 명확화**를 우선안으로 제시한다.

## 6. 권장 제작 순서와 검증

1. 동료 등록·직업 조건·서사 발동을 복구하고 기존 장면 자산 누락을 정리한다.
2. 여섯 직업에 ‘첫 만남 → 전문 행동 → 결과’가 이어지는 초반 묶음 하나씩을 만든다. 새로운 대형 시스템보다 현재 치료·프로젝트·거래·조우 기능을 사용한다.
3. 이전 [대화 확장 계획](2026-09-20-dialogue-interaction-plan.md)의 **직업당 핵심1+생활1, 총12개 시범**을 여기에 배치한다. 이번 제안을 이유로 별도60개를 추가해 범위를 두 배로 늘리지 않는다.
4. 첫 성공 연출6개와 공통 위험·첫 밤·길 찾기 표현을 연결한다. 긴 영상 확대는 이 묶음의 플레이 평가 뒤로 둔다.

수용 기준은 문안 개수가 아니라 다음과 같다.

- 초기 직업 목표 묶음에서 실제 NPC/접촉 상대와 의미 있는 선택1회, 전문 행동1회, 생활 행동1회, 위험 대응1회를 경험한다. 위험 대응은 반드시 전투 승리를 뜻하지 않는다.
- 같은 준비물을 갖고 시작해도 캐릭터에 따라 해결 순서·대상·소비·다음 단서가 다르다.
- 수집만으로 치료·설치·점화·작동 연출이 나오지 않는다. 새 환자 목표는 이미 끝낸 환자 기록으로 자동 완료되지 않는다.
- NPC 불참·사망, 재료 부족, 전투 후퇴, 불리한 난수·겨울에도 대체 진행이 남는다.
- 저장/로드·연타·장면 건너뛰기로 물품·신뢰·완료 보상이 중복되지 않는다. 기존 DialogueScene 큐와 미결 선택 복원을 재사용한다.
- 다음 장소를 몰라서 방사선 지역이나 한 구역만 반복 탐색하는 상황을 관찰하고, 지도 힌트·NPC 정보·분해 안내로 줄인다.
