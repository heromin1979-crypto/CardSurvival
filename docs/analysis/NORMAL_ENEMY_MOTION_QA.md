## 판정 기준

- 같은 행 안에서 준비 → 발동 → 회수 또는 상태 변화가 읽혀야 한다.
- 원거리 공격, 조준, 포효, 충전 준비는 제자리에서 재생한다.
- 돌진 계열인 `runner_rush`, `slam`, `charge_strike`만 대상 방향 `approach` 이동을 사용한다.
- 발바닥이나 쓰러진 몸의 하단 접지선이 셀 안에 머물고 프레임 경계를 침범하지 않아야 한다.
- 투명 배경, chroma 잔여, 빈 프레임을 자동 검사하고 프리뷰 checkerboard에서 다시 확인한다.
