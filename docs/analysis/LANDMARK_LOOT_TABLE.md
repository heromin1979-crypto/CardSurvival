## 1. 드랍 시스템 동작 방식

랜드마크 진입 후 세부 장소(sublocation)를 탐색하면 `_generateSubLocationLoot(sub)`가 호출된다.

1. 세부 장소별 `lootCount` `[min,max]` 범위에서 픽 수를 균등 추첨한다.
2. 각 픽마다 `weight / totalWeight` 비율로 항목 1개(수량 1 고정)를 추출한다.
3. 추출 항목의 정의가 없으면 해당 픽은 스킵된다.

### 구 표면 탐색과의 결정적 차이

| 항목 | 구 표면 (`generateDistrictLoot`) | 랜드마크 세부장소 (`_generateSubLocationLoot`) |
|---|---|---|
| 재획득 | 탐색할 때마다 반복 | **첫 방문 1회만** (`subLocationsLooted`에 기록, 리스폰 없음) |
| 픽 수 | 1~3 고정 | 세부장소별 `lootCount` |
| 재고 | 없음 | **W3-2 재고 시스템** — `lootCount[1]`(max)을 baseStock으로 두고 루팅 수만큼 차감, `stockRatio`로 픽 수 보정 |
| 수량 | `[minQty,maxQty]` | 픽당 1개 고정 |
| 1회 보상 | 없음 | `firstEnterReward` (캐릭터당 1회 자동 지급) |

> ⚠️ **기대 등장(min~max픽)** = `(Σ_{k=min..max} 1-(1-p)^k) / (max-min+1)`. 재고가 가득 찬 첫 방문 기준이며, 재고 소진 시 실제 픽 수는 줄어든다.
