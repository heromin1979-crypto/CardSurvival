## 1. 드랍 시스템 동작 방식

탐색(`Explore`) 시 `generateDistrictLoot(districtId)` 함수가 호출되어 다음 절차로 보상이 생성된다.

1. 해당 구의 `lootTable` 항목들의 `weight` 합계(`totalWeight`)를 계산한다.
2. **1회 탐색당 1~3개**(`lootCountMin`~`lootCountMax`)의 픽을 수행한다. 기대값 = 2회.
3. 각 픽마다 `weight / totalWeight` 비율로 항목을 추출한다.
4. 추출된 항목의 수량은 `[minQty, maxQty]` 범위에서 균등 분포로 결정된다.
5. `contamChance`가 있으면 해당 확률로 오염도 50~100이 부여된다(식수 등).

### 확률 표기

- **1픽 확률** = `weight / totalWeight`
- **기대 등장 확률** = 1회 탐색(1~3픽 평균) 중 해당 아이템이 최소 1번 등장할 확률 = (Σ_{k=1..3} 1-(1-p)^k) / 3

> ⚠️ 본 문서는 **구 단위(`district`) 표면 탐색 lootTable**만 다룬다.
> 드랍 표는 **구 / 랜드마크 자체 / 세부장소 3계층으로 완전히 분리**돼 있다 — 나머지 두 계층과 계층별 차이는
> [`LANDMARK_LOOT_TABLE.md`](./LANDMARK_LOOT_TABLE.md) 참조. 낚시(`hasFishing`), 환경 오브젝트 분해 보상은 별도 시스템이며 본 문서에서 제외한다.

## 4. 카테고리 인사이트

### 4.1 위험도별 특징

- **🟢 위험도 1 (안전):** 자연 채집(`stream_spring`, `pine_nut`, `wild_strawberry`, `acorn`)과 기본 생활 자원이 풍부. 채집형 직업(약사·셰프)의 초반 거점.
- **🟡 위험도 2 (보통):** 주거·시장 잔류물(`cloth`, `water_bottle`, `wood`)이 안정적. 산업 구(구로·금천·성동)는 `electronic_parts`·`sulfur`·`saltpeter` 등 화학/기술 재료가 추가.
- **🟠 위험도 3 (위험):** 한강 변 거점(강남·마포·용산·성동). `circuit_board`, `sand` 등 가공품 재료가 늘지만 raw food(`herb`, `wild_berry`, `vegetable`)는 가중치 0.5배로 감소.
- **🔴 위험도 4 (극위험):** 영등포(KBS)·서대문(세브란스)·서초. 의약품 원료(`herb`)·방송장비(`circuit_board`)가 핵심 보상.
- **⚫ 위험도 5 (치명):** 종로(`radiation:10`)·중구·송파. 방사선 오염 `contaminated_water`(오염 50~80%)와 화학 재료(`sulfur`)가 메인. raw food 가중치 0.5배 유지.

### 4.2 자원 군집

| 자원군 | 주요 출현 지역 |
|---|---|
| 식수(`rainwater`/`water_bottle`) | 한강 변 구(강남·마포·동작·광진·송파·강동·성동·용산·영등포·중구), 주거 외곽(노원·양천·은평·서대문·도봉) |
| 오염수(`contaminated_water`) | 강북·도봉·중랑(자연 식수 모방), 금천·성동(`50%`), 종로(`80%` — 극심) |
| 산업 금속(`scrap_metal` 가중치 20+) | 구로(35), 금천(40), 성동(40), 강서(30), 종로(25), 영등포(25), 서초(25), 송파(25), 마포(25), 용산(20) |
| 전자부품(`electronic_parts`/`circuit_board`) | 용산(25/5), 구로(15/5), 금천(12/5), 성동(15/5), 영등포(10/5), 강서(0/5) |
| 천·가죽(`cloth`/`leather`/`thread`) | 동대문(35/15/15), 중구(30/12/10), 성동(5/10) — 봉제 시장 잔존 |
| 산악 채집(`pine_nut`/`wild_strawberry`/`chestnut`/`apple_wild`) | 도봉·은평·노원·강북·관악(북한산·도봉산·관악산·수락산 자락) |
| 화학(`sulfur`/`saltpeter`) | 구로·금천·성동(공장 잔류), 종로(폐허 잔재) |
| 모래(`sand`) | 한강 변 한정(강남·강동·광진·동작·마포·송파) |
| 개울 수원(`stream_spring`) | 산악 구 한정(강북·관악·노원·도봉 — 가중치 12~15) |

### 4.3 raw food 가중치 규칙(PR11)

- **일반 구역(`dangerLevel ≤ 2`):** `herb`/`wild_berry`/`vegetable` 각각 **weight 8** (1.0배)
- **위험 구역(`dangerLevel ≥ 3`):** **weight 4** (0.5배) — 위험 보상은 가공품·전략 자원으로 분리
- **dobong**(`dl=1` 예외): `vegetable` weight 4 — 협의서 v4 §3.1 정합 처리(산악 야영지 컨셉)
