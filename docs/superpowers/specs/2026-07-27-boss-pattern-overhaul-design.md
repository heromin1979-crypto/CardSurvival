# 네임드 보스 패턴 및 전용 모션 개편 설계

**작성일:** 2026-07-27
**상태:** 사용자 승인 완료
**대상:** `SECRET_ENEMIES`의 `isBoss: true` 보스 21종

## 1. 목표

모든 네임드 보스가 다음 행동 구성을 실제 전투에서 보장하도록 개편한다.

- 기존 `attack` 기반 기본공격 1개
- 일반공격 기술 1~2개
- 소환·버프·전장 변화 등 특수기 1개
- HP 30% 이하에서 전투당 1회 사용하는 필살기 1개

기술 개수만 채우지 않고 다음 문제를 함께 해결한다.

- UI에 표시한 의도와 실제 실행 행동이 달라질 수 있는 문제
- 장기 예고 기술과 필살기 예고가 한 상태를 덮어쓸 수 있는 문제
- 소환·버프 기술이 공격 명중·회피·최소 피해 경로를 통과하는 문제
- 데이터에 선언됐지만 실행되지 않는 보스 효과
- 페이즈 자동 소환·광역 효과와 명시적 기술의 중복
- 일반공격·특수기·필살기가 같은 스프라이트 행을 사용하는 문제
- 전용 스프라이트시트가 없는 보스의 타입별 이미지 대체

## 2. 현재 구현 근거

### 보스 데이터

- `js/data/secretEnemies.js`
- `SECRET_ENEMIES` 안의 `isBoss: true` 정의 21종
- 모든 보스에 기본 `attack`이 있다.
- 현재 `specialSkills`는 공격·소환·버프·반격·필살기 후보를 구분하지 않고 함께 보관한다.
- 명시적인 필살기 필드와 공통 발동 규칙은 없다.

### AI 및 효과 실행

- `js/systems/combat/CombatAiTurns.js`
- `_decideNextIntent()`는 준비된 기술을 의도로 표시한다.
- `_runEnemyAI()`는 행동 시점에 기술 사용 확률을 다시 판정한다.
- `_runSingleEnemyTurn()`은 `timedThreat`를 일반 AI보다 먼저 처리한다.
- `_applyBossPhaseTriggers()`는 페이즈 진입 시 쿨다운 초기화, 자동 소환, 확률형 광역 공격을 처리한다.
- `_executeEnemySpecialSkill()`은 피해가 없는 유틸리티 기술도 공격 경로로 처리한다.

### 현재 모션

- `js/ui/combat/combatUiAssets.js`
- `js/ui/combat/CombatFxPlayer.js`
- `css/screens-combat.css`
- `docs/analysis/MONSTER_MOTION_AUDIT.md`

현재 보스 21종 중 전용 시트가 있는 보스는 7종이며, 나머지 14종은 타입 기반 시트로 대체될 수 있다. 기존 시트의 네 행은 다음 용도를 공유한다.

1. 대기
2. 공격·특수기·전진
3. 피격·디버프·밀치기
4. 사망

`motion-zombie-lunge`, `motion-zombie-heavy`, `motion-zombie-spit`, `motion-zombie-scream`은 모두 같은 공격 행을 재생한다. CSS 변형만 달라 기술별 동작을 표현할 수 없다.

## 3. 선택한 접근

기존 `specialSkills` 배열에 예외를 계속 추가하지 않고 보스 전용 패턴 컨트롤러를 도입한다.

```js
bossPattern: {
  normalSkills: [],
  specialSkill: {},
  ultimate: {
    hpThreshold: 0.3,
    telegraphTurns: 1,
    oncePerCombat: true
  },
  passives: []
}
```

기존 `attack`은 기본공격 정의로 유지한다. 일반 몬스터의 기존 `specialSkills`와 `timedThreat`는 이번 범위에서 마이그레이션하지 않는다.

## 4. 보스 행동 상태

보스 인스턴스는 다음 런타임 상태를 가진다.

```js
_bossActionState: {
  committedAction: null,
  ultimatePending: false,
  ultimateUsed: false,
  normalCursor: 0
}
```

`committedAction`은 UI 의도와 실제 실행이 공유하는 단일 행동 결정이다.

```js
committedAction: {
  actionId: 'alpha_hunt',
  category: 'ultimate',
  state: 'telegraphing',
  motionKey: 'alpha_hunt',
  targetId: 'player',
  remainingTelegraphTurns: 1
}
```

전투 저장 데이터에는 필살기 예약·사용 여부와 진행 중인 카운트다운을 포함한다. 전투가 끝나거나 보스가 죽으면 상태를 제거한다.

`state`는 `planned`, `telegraphing`, `ready` 중 하나다. 일반 행동은 이전 행동이 끝날 때 한 번만 `planned`로 결정하며 실행 시 다시 추첨하지 않는다. 대상이 죽거나 위치 조건이 무효가 된 경우에만 같은 행동의 합법적인 대상을 다시 선택한다.

## 5. 행동 우선순위

보스의 자기 턴은 다음 순서로 처리한다.

1. 사망·행동 불능 확인
2. 이미 예고된 행동의 카운트다운 또는 발동
3. 예약된 필살기의 예고 또는 발동
4. 조건을 만족하고 쿨다운이 끝난 특수기
5. 사용 가능한 일반공격
6. 기본공격

기절은 현재 예고를 삭제하지 않고 보스 행동 한 턴만 지연한다. 기절된 턴에는 예고 숫자도 감소하지 않는다.

## 6. 필살기 공통 규칙

- 모든 보스는 HP 30% 이하에서 필살기를 예약한다.
- 전투당 한 번만 예약·사용한다.
- 필살기 예고는 보스 행동 1회를 소비한다.
- 다음 보스 행동에 필살기를 발동한다.
- 이미 다른 기술을 예고 중이면 기존 기술을 완료하거나 취소 판정을 끝낸 뒤 필살기를 예고한다.
- 필살기가 예약된 뒤에는 새로운 장기 예고 일반·특수 기술을 시작하지 않는다.
- 일반 피격으로 필살기 예약을 삭제하지 않는다.
- 기술별로 명시한 카운터만 필살기를 약화하거나 취소한다.
- 한 번의 피해로 여러 기존 페이즈 임계점을 통과해도 필살기는 한 번만 예약한다.
- 회복으로 HP가 다시 30%를 넘어가도 예약은 유지하며 재사용은 불가능하다.
- 소환된 부하는 보스의 필살기 상태를 공유하지 않는다.

임계점 판정은 보스가 피해를 받고 살아남은 직후 수행한다. 아직 예고를 시작하지 않은 `planned` 일반 행동은 필살기 예고로 교체하고 의도 UI를 즉시 갱신한다. 이미 `telegraphing` 중인 행동은 유지하고 `ultimatePending`만 설정한다. `ultimateUsed`는 필살기 예고를 시작할 때 `true`가 되며, 기술별 카운터로 필살기가 취소되더라도 다시 예약하지 않는다.

### 장기 예고와 겹칠 때

장기 예고를 먼저 완료하고 필살기를 직렬 실행한다.

```text
특수기 예고 2
→ 특수기 예고 1
→ 특수기 발동 또는 취소
→ 필살기 예고 1
→ 필살기 발동
```

## 7. 기술 선택과 쿨다운

기본 리듬은 다음을 목표로 한다.

```text
기본공격 → 일반공격 → 기본공격/일반공격 → 특수기
```

- 일반공격은 순환 선택하며 같은 기술을 연속 사용하지 않는다.
- 기본공격은 최소 2턴에 한 번 후보가 된다.
- 일반공격 기본 쿨다운은 2~3 보스 턴이다.
- 특수기 기본 쿨다운은 4~6 보스 턴이다.
- 기술별 조건이 공통 주기보다 우선한다.
- 소환수 상한에 도달하면 소환기를 선택하지 않는다.
- 회복기는 HP 조건을 만족할 때만 선택한다.
- 같은 버프가 남아 있으면 해당 버프기를 선택하지 않는다.
- 쿨다운은 실제 발동 또는 취소 판정이 끝난 시점부터 계산한다.
- 선택 가능한 기술이 없으면 기본공격을 사용한다.

`3턴 예고`의 표시는 다음 의미로 통일한다.

```text
예고 3 → 예고 2 → 예고 1 → 발동
```

## 8. 공격형·비공격형 전달 방식

기술 정의에 `delivery`를 둔다.

```js
delivery: 'attack' | 'self' | 'summon' | 'battlefield'
```

- `attack`: 명중·회피·방어·피해·상태이상 처리
- `self`: 회복·방어·회피·무적 등 자기 효과
- `summon`: 소환 한도와 배치 가능 여부 처리
- `battlefield`: 광역 장판·환경·진형 효과 처리

`self`와 `summon`은 공격 명중 판정과 최소 1 피해 보정을 통과하지 않는다.

## 9. 공통 효과 처리

현재 데이터에 있으나 전용 실행 처리가 없거나 불완전한 효과를 공통 처리기에 연결한다.

- `armorPiercing`: 지정 비율만큼 방어력 무시
- `durabilityLoss`: 명중 시 지정 장비 내구도 감소
- `noise`: `NoiseSystem`을 통한 전투 소음 증가
- `executeThreshold`: 즉사 대신 기준 HP 이하에서 추가 피해
- `guaranteedFirstStrike`: 전투 최초 행동 예약
- `resistanceType`: 지정 주기 또는 최근 피해 속성에 따른 저항 전환
- `counterAttack`: 정해진 횟수 제한을 둔 반격
- `weaponFreeze`: 지정 턴 동안 해당 무기 사용 제한
- `healingReceivedMultiplier`: 모든 아군 회복 경로에 적용되는 받는 치료 배율

즉사, 영구 무적, 영구 장비 잠금은 사용하지 않는다. 상태 효과는 UI에 남은 턴과 대응 방법을 표시한다.

## 11. 필살기별 전투 퍼즐

### 제로 환자 — 숙주 폭주

현재 플레이어 감염 수치가 높을수록 피해와 바이러스 지속시간이 증가한다. 감염 관리가 직접적인 대응 수단이다.

### 방사선 거인 — 임계 질량

예고 중 지정 피해량을 주면 노심이 불안정해져 발동 피해와 방사선이 절반으로 감소한다. 실패하면 전체 피해와 방사선 축적이 발생한다.

### 산성 여왕 — 완전 부식

현재 장착 방어구를 표적으로 삼아 방어력과 내구도에 집중 피해를 준다. 방어 행동은 내구도 피해를 완화한다.

### 무리의 어미 — 어미의 포식

살아 있는 소환수를 흡수해 소환수마다 HP를 회복하고 다음 강타를 강화한다. 필살기 전에 소환수를 제거하면 위력이 감소한다.

### 얼어붙은 거인 — 빙결 감옥

예고 시점의 랭크를 얼린 뒤 다음 턴 해당 랭크를 붕괴시킨다. 다른 랭크로 이동하면 주 피해를 피할 수 있다.

### 약탈자 두목 — 처형 명령

살아 있는 약탈자들이 표시된 대상을 순서대로 사격한다. 남은 부하 수가 타격 횟수가 된다.

### 유령 저격수 — 헤드샷

예고 시점의 랭크를 조준한다. 대상 HP가 낮을수록 추가 피해를 주지만 즉사시키지는 않는다. 이동과 방어가 대응 수단이다.

### 교단 교주 — 피의 의식

신도를 희생해 광역 피해와 공포를 가한다. 신도가 없으면 교주가 자신의 HP를 대가로 사용한다.

### 변이 호랑이 — 포식자의 사냥

대상을 표시한 뒤 다음 턴 연속 도약한다. 도발과 방어로 표적을 보호할 수 있다.

### 하수도의 왕 — 오수 역류

아군 진형을 교란하고 감염 장판을 만든다. 이동 여유와 감염 관리가 필요하다.

### 변이 여왕벌 — 왕실 산란

아군에게 알 상태를 부여하고 2턴 뒤 부화시켜 독 피해를 준다. 상태 치료로 부화를 제거할 수 있다.

### 야생견 알파 — 알파의 사냥

알파가 먼저 물고 살아 있는 야생견이 연계 공격한다. 무리를 먼저 줄이면 연타 횟수가 감소한다.

### 미친 재벌 — 현상금 선고

가장 약한 아군을 표시하고 경호원과 함께 집중 공격을 준비한다. 도발로 표적을 바꾸거나 경호원을 제거할 수 있다.

### 실험체 X — 완전 적응

최근 받은 피해 속성에 높은 저항을 얻고 해당 속성으로 반격한다. 다른 공격 속성으로 전환해야 한다.

### 눈보라의 망령 — 백색 소멸

무기를 동결하고 명중률을 낮춘 뒤 위치를 바꾼다. 무기 외 기술과 투척물을 활용할 수 있다.

### 탈영한 전우 — 교차 사격

전열과 후열을 순서대로 포격한다. 의도 UI에 안전 랭크를 표시해 위치 이동으로 대응하게 한다.

### 감염된 이재훈 — 백드래프트

표시한 랭크와 인접 랭크에 폭발·화상·밀치기를 가한다. 폭발 범위 밖으로 이동할 수 있다.

### 빚쟁이 사채업자 — 강제 추심

사기를 먼저 감소시키고 감소량과 생존 건달 수에 비례해 연계 피해가 증가한다.

### 변이 셰프 — 도축 시간

출혈 상태인 대상을 집중 난도질한다. 출혈이 없으면 타격 횟수와 피해가 감소한다.

### 감염된 동료 의사 — 최종 수술

치료 감소 상태를 부여한 뒤 고관통 공격을 가한다. 방어와 상태 해제가 대응 수단이다.

### 식량 군벌 — 굶주림의 지배

아군 전체가 받는 치료를 2턴 동안 50% 감소시킨다. 감소로 차단된 회복량 일부는 식량 군벌의 임시 보호막으로 전환한다.

- 방어 상태로 받으면 치료 감소율은 25%로 완화한다.
- 의료 아이템, 플레이어 기술, 동료 기술, 자동 치료에 동일하게 적용한다.
- 죽음의 문턱 해제에 필요한 최소 회복은 유지한다.
- 식량·의료품 카드는 삭제하거나 오염시키지 않는다.
- 지속시간은 `remainingPlayerTurns: 2`인 전장 상태로 보관하고 플레이어 행동 종료 때만 1씩 감소한다. 이 기간 안에 발생한 동료 치료도 같은 배율을 적용한다.

## 12. 중복 패턴 정리

- 소환은 `specialSkill` 또는 `ultimate` 한 곳에서만 주도한다.
- 광역 공격은 명시적인 행동으로만 발동한다.
- 기존 `phaseThresholds`의 자동 소환과 확률형 광역 공격은 제거한다.
- 페이즈 임계점은 필살기 예약과 시각적 전환에 사용한다.
- 재생·독혈 반격처럼 행동을 소비하지 않는 능력은 `passives`로 이동한다.
- `attacksPerRound`의 무조건 반복 대신 각 행동의 `hits`를 사용한다.

## 13. 보스 모션 계약

보스 전용 시트는 6열 × 8행을 기본으로 한다.

```text
0: idle
1: basicAttack
2: normalSkill1
3: normalSkill2
4: specialSkill
5: ultimate
6: hit
7: death
```

일반공격이 하나인 보스는 3번 행을 2번 행으로 대체할 수 있다. 전진·밀치기·디버프는 위치 이동과 오버레이로 처리한다.

### 매니페스트

`assets/images/combat/spritesheets/manifest.json`에 기술별 행과 연출 메타데이터를 저장한다.

```json
{
  "boss_feral_dog_alpha_sheet.png": {
    "cols": 6,
    "rows": 8,
    "motions": {
      "idle": 0,
      "basicAttack": 1,
      "neck_bite": 2,
      "frenzy_bite": 3,
      "pack_howl": 4,
      "alpha_hunt": 5,
      "hit": 6,
      "death": 7
    }
  }
}
```

모션 항목은 필요에 따라 다음 값을 가진다.

- `durationMs`
- `impactFrame`
- `movement`: `none`, `lunge`, `advance`, `retreat`
- `loop`
- `camera`

`CombatFxPlayer`는 `fx` 문자열로 모션을 추측하지 않고 `committedAction.motionKey`를 사용한다. 레거시 몬스터는 기존 4행 매핑으로 폴백한다.

## 16. 모션 품질 기준

- 프레임마다 캐릭터 크기와 바닥 기준점이 일정해야 한다.
- 직접 공격은 준비, 접촉, 복귀 단계가 보여야 한다.
- 공격 부위는 대상 방향을 향해야 한다.
- 소환·버프·울부짖음은 공격 접촉처럼 보이지 않아야 한다.
- 고정형 기술에는 자동 전진 이동을 적용하지 않는다.
- 필살기는 일반공격보다 준비 자세와 실루엣 변화가 커야 한다.
- 피격 행을 공격 행으로 재사용하지 않는다.
- 사망 마지막 프레임은 반복하지 않고 고정한다.
- 피해 숫자, 히트스톱, 카메라 흔들림은 `impactFrame`에 맞춘다.
- 투명 영역의 RGB 잔존값까지 검사해 녹색 테두리와 도트를 제거한다.
- 캐릭터 내부의 원래 녹색·산성색 픽셀은 보존한다.

## 17. 호환성 및 실패 처리

- 보스 전용 `bossPattern`이 없으면 기존 일반 적 AI로 폴백한다.
- 매니페스트 또는 기술 모션 키가 없으면 해당 범주의 기본 행으로 폴백한다.
- 소환 공간이 부족하면 가능한 수만 소환하고 실패한 수는 재시도하지 않는다.
- 대상이 죽거나 유효하지 않으면 발동 직전에 합법적인 대상으로 다시 결정한다.
- 저장 데이터에 신규 상태가 없으면 기본 상태를 초기화한다.
- 제거된 레거시 필드는 역직렬화 시 무시한다.
- 필살기 상태와 UI 의도가 불일치하면 런타임 상태를 기준으로 의도를 재생성한다.

## 18. 검증 기준

### 데이터 검증

- 모든 `isBoss: true` 정의에 `bossPattern`이 존재한다.
- 일반공격 기술은 1~2개다.
- 특수기는 정확히 1개다.
- 필살기는 정확히 1개이며 임계점은 0.3이다.
- 모든 기술 ID, 효과 키, 소환 대상, 모션 키가 유효하다.

### AI 검증

- 표시된 의도와 실행 행동이 일치한다.
- 기존 장기 예고가 필살기에 덮어써지지 않는다.
- 필살기는 전투당 한 번만 예약·발동한다.
- 기절 시 예고 카운트가 감소하지 않는다.
- 저장·불러오기 후 예약과 카운트다운이 유지된다.
- 소환·버프 기술이 공격 피해를 만들지 않는다.

### 보스별 검증

- 부하 연계 필살기는 생존 부하 수에 따라 위력이 달라진다.
- 위치 대응 필살기는 표시한 랭크와 실제 판정이 일치한다.
- 상태 관리형 필살기는 치료·해제 시 위력이 감소한다.
- 방사선 거인의 피해 누적 카운터가 성공·실패 결과를 구분한다.
- 식량 군벌의 치료 감소가 모든 아군 회복 경로에 적용된다.

### 모션 검증

- 21종 모두 전용 시트 키를 가진다.
- 매니페스트의 행 수와 실제 PNG 크기가 일치한다.
- 모든 기술의 `motionKey`가 유효하다.
- 소환·버프 모션에는 자동 전진이 없다.
- 접촉 프레임과 피해 연출이 일치한다.
- 완전 투명 픽셀에 녹색 RGB 잔존값이 없다.
- 프레임별 바닥 기준점과 바운딩박스 편차가 허용 범위 안이다.
