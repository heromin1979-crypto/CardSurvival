# 플레이어 원거리 무기 탄창·재장전 시스템 설계

## 1. 목적

플레이어가 사용하는 원거리 발사 무기에 무기별 20발 탄창을 도입한다. 탄약은 즉시 발사에 소비되는 낱발 자원이 아니라, 빈 탄창을 채우는 20발 세트 카드로 취급한다. 플레이어는 전투에서 원거리 주무기와 근접 보조무기 또는 맨손 공격을 선택할 수 있다.

NPC는 플레이어의 장비·탄창·탄약 카드 시스템을 사용하지 않는다. 군인, 탈영병, 민준 등은 캐릭터 정의에 포함된 고정 장비 콘셉트와 NPC별 전투 스킬·전투력에 따라 공격한다.

## 2. 확정 요구사항

- 적용 대상은 `combat.requiresAmmo`가 있는 플레이어 장착 무기 전체다.
  - 권총, 산탄총, 소총, M4 카빈, 저격소총, 특수 소총, 소음기 권총
  - 석궁, 정밀 석궁
- 모든 적용 무기의 탄창 용량은 20발이다.
- 신규 무기와 `loadedAmmo`가 없는 기존 저장 데이터의 무기는 `0/20`으로 시작한다.
- 탄약 카드 `quantity` 1은 20발 세트 1장을 뜻한다.
  - 예: 권총 탄약 `×6`은 20발 세트 6장이다.
- 빈 탄창에서 재장전하면 호환 탄약 세트 `quantity`를 1 소비하고 `20/20`이 된다.
- 재장전은 전투 행동 1회를 소비한다.
- 발사 공격은 명중 여부와 관계없이 공격 1회당 정확히 1발을 소비한다.
- 산탄총 다중 대상 공격도 공격 1회당 1발만 소비한다.
- 탄창이 남아 있으면 재장전할 수 없다.
- 전투가 끝나거나 무기를 해제·교체하거나 저장·불러오기해도 잔탄이 유지된다.
- 총기를 근접무기로 사용하는 폴백은 허용하지 않는다.
- 원거리 숙련도의 탄약 미소모 확률은 플레이어 장착 무기 공격에 적용하지 않는다.
- NPC는 탄약 카드, 탄창, 재장전, 장착 무기 인스턴스를 사용하지 않는다.

## 3. 장비 슬롯 모델

### 3.1 원거리 주무기

`player.equipped.weapon_main`은 `combat.requiresAmmo`가 있는 원거리 발사 무기만 허용한다.

- `subtype: firearm`
- `subtype: ranged`이면서 `combat.requiresAmmo`가 있는 석궁 계열

### 3.2 근접 보조무기

`player.equipped.weapon_sub`는 `subtype: melee`인 근접 무기만 허용한다.

- 방패·보조 방어구 제외
- 투척 무기 제외
- 총기·석궁 제외

### 3.3 기존 저장 데이터 마이그레이션

저장 데이터에서 슬롯이 반대로 사용된 경우 다음 순서로 정규화한다.

1. `weapon_main`에 근접 무기, `weapon_sub`에 원거리 무기가 있으면 두 슬롯을 교환한다.
2. 한쪽 슬롯만 사용 중이고 반대 슬롯 유형의 무기라면 올바른 빈 슬롯으로 이동한다.
3. 새 규칙에 맞지 않는 방패·투척 무기·기타 장비는 장착을 해제하고 보드에 배치한다.
4. 보드 공간이 없으면 기존 `pendingLoot` 복구 경로로 넘겨 아이템 손실을 막는다.

## 4. 상태 모델

### 4.1 무기 인스턴스

원거리 무기 카드 인스턴스가 다음 상태를 소유한다.

```js
{
  instanceId: 'c123',
  definitionId: 'pistol',
  loadedAmmo: 0
}
```

- 유효 범위: `0..20`
- 필드 누락, 음수, `NaN`, 20 초과 값은 조회 시 `0..20` 범위로 정규화한다.
- `GameState.cards`는 기존 직렬화 대상이므로 별도 전투 임시 상태를 만들지 않는다.

### 4.2 탄약 세트

무기 정의의 `combat.requiresAmmo`가 호환 탄약 정의 ID를 제공한다.

| 무기 | 호환 탄약 세트 | 장전 결과 |
|---|---|---:|
| 권총 계열 | `pistol_ammo` | 20발 |
| 산탄총 | `shotgun_ammo` | 20발 |
| 소총 계열 | `rifle_ammo` | 20발 |
| 석궁 계열 | `crossbow_bolt` | 20발 |

탄약 카드가 중첩돼 있으면 재장전 성공 시 해당 카드 인스턴스의 `quantity`만 1 감소한다. 0이 되면 카드 인스턴스를 제거한다.

## 5. 시스템 경계

### 5.1 `WeaponAmmoSystem`

신규 `js/systems/WeaponAmmoSystem.js`가 탄창과 재장전 규칙의 단일 진실 공급원이 된다.

예상 공개 인터페이스:

```js
isMagazineWeapon(definition)
getMagazineCapacity(definition)
getLoadedAmmo(gameState, weaponInstanceId)
getMagazineState(gameState, weaponInstanceId)
findCompatibleAmmoPack(gameState, weaponInstanceId)
canReload(gameState, weaponInstanceId)
reload(gameState, weaponInstanceId)
canFire(gameState, weaponInstanceId)
consumeRound(gameState, weaponInstanceId)
```

책임:

- 적용 대상 판별
- 잔탄 정규화
- 호환 탄약 세트 탐색
- 원자적인 재장전과 탄약 카드 소비
- 원자적인 1발 소비
- 카드 제거·보드 갱신 이벤트 발생

비책임:

- 턴 진행
- 대상 선택
- 피해·명중 계산
- NPC 공격력 계산
- DOM 렌더링

### 5.2 `GameState`

- `createCardInstance()`는 탄약 요구 무기에 `loadedAmmo: 0`을 초기화한다.
- `deserialize()`는 기존 저장 데이터의 장비 슬롯을 정규화하고 원거리 무기의 누락된 `loadedAmmo`를 0으로 보정한다.
- `serialize()`는 기존처럼 카드 인스턴스 전체를 저장하므로 별도 필드 추가가 필요 없다.

### 5.3 `EquipmentSystem`

- `weapon_main`을 원거리 발사 무기 전용으로 제한한다.
- `weapon_sub`를 근접 무기 전용으로 제한한다.
- 장비 모달과 카드 상세의 장착 가능 슬롯도 동일한 규칙을 사용한다.

### 5.4 `CombatSkillSystem`

플레이어 loadout은 다음 공격 행동을 생성한다.

1. 유효한 원거리 주무기가 있으면 장비 원거리 공격
2. 유효한 근접 보조무기가 있으면 장비 근접 공격
3. 근접 보조무기가 없으면 `basic_strike` 맨손 공격
4. 캐릭터 고유 비공격 스킬

NPC loadout은 `COMPANION_COMBAT_LOADOUTS`의 고정 스킬과 공용 유틸리티만 사용한다. `npcs.states[*].equippedWeapon`과 `equippedTool`을 장비 공격으로 변환하지 않는다.

### 5.5 `CombatSystem`과 `CombatRankedEffects`

플레이어 원거리 공격 검증:

- 활성 전투원이 플레이어인지 확인
- 원거리 스킬의 `equipmentInstanceId`가 현재 원거리 주무기인지 확인
- `WeaponAmmoSystem.canFire()`가 거짓이면 `empty_magazine`으로 거부

비용 소비:

- 공격 실행이 검증된 뒤 `consumeRound()`로 1발 소비
- 명중 판정 전에 비용을 소비하므로 빗나가도 1발이 소모된다.
- 보드 탄약 카드의 `quantity`는 발사할 때 직접 소비하지 않는다.

재장전 명령:

```js
reloadActiveWeapon(instanceId)
```

- 활성 전투원이 플레이어
- 전투 단계가 플레이어 입력 대기
- 지정 무기가 현재 원거리 주무기
- 탄창이 0
- 호환 탄약 세트가 존재

조건을 만족하면 `WeaponAmmoSystem.reload()`를 실행하고 전투 로그와 UI 이벤트를 기록한 뒤 행동 1회를 소비하여 턴을 진행한다. 실패하면 자원과 턴을 소비하지 않는다.

레거시 `_attackAction()`은 탄약이 없을 때 근접 피해로 전환하지 않는다. 빈 탄창이면 피해·내구도·소음·턴을 소비하지 않고 실패한다.

## 6. NPC 고정 장비 콘셉트

NPC는 인벤토리 장비 카드가 아니라 캐릭터 고유 전투 스킬로 무장을 표현한다.

- 군인·탈영병: 고정 소총 계열 스킬
- 민준·소희: 고정 권총 계열 스킬
- 간호사·의사·기술자 등: NPC 정의에 연결된 고정 근접·지원 스킬

NPC 원거리 공격은 다음을 사용한다.

- `COMBAT_SKILLS`의 피해·명중 기본값
- NPC 정의의 `companion.combatDmg`에 따른 개별 공격력 배율
- 기존 위치·사거리·상태 효과 규칙

`CombatantAdapter.buildCombatants()`는 동료 전투원에 `combatDamageMultiplier`를 기록한다.

- `companion.combatDmg`가 0보다 큰 유한한 수이면 해당 값을 사용한다.
- 값이 없거나 0 이하이거나 비정상이면 `1.0`을 사용한다.
- 예: 부상당한 군인 `1.3`, 탈영병 `1.4`, 군견 `0.2`

`CombatRankedEffects._applyRankedDamageEffect()`는 `sourceType === 'companion'`인 공격자의 기본 피해와 치명타 계산 뒤 이 개별 배율을 적용한다. 이 값은 `NPCSystem.getCompanionCombatBonus()`가 플레이어 공격에 제공하는 파티 합산 보너스와 별개이며, 동료 자신의 공격에 합산 보너스를 중복 적용하지 않는다.

다음은 사용하지 않는다.

- `GameState.cards` 무기 인스턴스
- 플레이어 탄약 카드
- `loadedAmmo`
- 재장전 행동
- 플레이어 원거리 숙련도

## 7. UI 설계

### 7.1 장비 화면

- `weapon_main`: `원거리 주무기`
- `weapon_sub`: `근접 보조무기`
- 장착 후보와 장착 버튼은 `EquipmentSystem`의 슬롯 규칙을 그대로 따른다.

### 7.2 전투 명령 덱

플레이어 턴에는 원거리와 근접 계열을 동시에 표시한다.

원거리 카드 상태:

| 상태 | 제목·동작 | 활성 여부 |
|---|---|---|
| `loadedAmmo > 0` | 원거리 무기명·공격, `잔탄 N/20` | 활성 |
| `loadedAmmo === 0`, 탄약 세트 있음 | `재장전`, `20발 세트 1개 소비` | 활성 |
| `loadedAmmo === 0`, 탄약 세트 없음 | `탄약 없음`, 호환 탄약명 표시 | 비활성 |

근접 카드 상태:

- 보조무기 있음: 보조무기명·피해·명중 표시
- 보조무기 없음: 맨손 공격·피해·명중 표시
- 원거리 탄약 상태와 독립적으로 활성화

재장전은 대상을 요구하지 않는다. 원거리 카드 클릭 한 번으로 명령을 실행하고 턴을 종료한다.

### 7.3 일반 카드와 상세 모달

원거리 무기 카드:

- 카드 표면에 `N/20` 잔탄 배지
- 0발: `--text-danger`
- 1발 이상: `--accent-primary`

카드 상세 모달:

- `장전 탄약 N/20`
- `호환 탄약 <이름>`

탄약 카드:

- 기존 `×quantity` 표시 유지
- 설명과 상세 정보에 `1세트 = 20발` 표시

기존 디자인 토큰과 compact industrial UI를 유지하며 새 색상·폰트·간격 토큰을 만들지 않는다.

## 8. 오류 처리와 불변식

- UI 상태와 무관하게 시스템 명령 검증에서 빈 탄창 공격을 거부한다.
- 실패한 공격은 탄약, 내구도, 소음, 턴을 소비하지 않는다.
- 실패한 재장전은 탄약 세트와 턴을 소비하지 않는다.
- 성공한 공격은 명중 여부와 관계없이 정확히 1발을 소비한다.
- 성공한 재장전은 정확히 탄약 세트 1개와 행동 1회를 소비한다.
- 탄창은 0 미만 또는 20 초과가 될 수 없다.
- 탄창이 1발 이상이면 재장전할 수 없다.
- NPC 고정 스킬은 탄창 검증에 들어가지 않는다.
- 원거리 무기 카드가 파괴되면 해당 인스턴스의 잔탄도 카드와 함께 제거된다.
- 무기 해제·교체만으로는 잔탄이 변하지 않는다.

## 9. 테스트 전략

### 9.1 단위 테스트

`tests/unit/WeaponAmmoSystem.test.js`

- 신규·필드 누락 무기 0발
- 호환 탄약 세트 1개 소비 후 20발
- 중첩 탄약 `×6 → ×5`
- 마지막 세트 소비 시 카드 제거
- 20발 초과·음수·비정상 잔탄 정규화
- 탄창이 남았을 때 재장전 거부
- 1발 소비와 0발 소비 거부
- 잘못된 무기·비호환 탄약 거부

장비 시스템 테스트:

- 원거리 무기는 `weapon_main`만 허용
- 근접 무기는 `weapon_sub`만 허용
- 방패·투척 무기는 두 무기 슬롯에서 거부

### 9.2 전투 테스트

- 빈 탄창 원거리 공격 명령 거부
- 잔탄이 있으면 공격 가능
- 명중·빗나감 모두 1발 소비
- 산탄총 다중 대상 공격 1발 소비
- 재장전 성공 시 세트 1개와 턴 소비
- 탄약 세트가 없으면 재장전 실패, 턴 유지
- 근접 보조무기와 원거리 주무기 동시 loadout
- 보조무기가 없으면 맨손 공격 제공
- 레거시 무탄약 근접 폴백 제거
- NPC 장착 필드가 존재해도 고정 loadout 유지
- NPC 원거리 공격이 플레이어 탄약을 소비하지 않음
- 군인·탈영병 등 NPC의 고정 무기 공격에 본인의 `combatDmg` 배율 적용
- `combatDmg`가 없거나 0 이하인 NPC의 개별 공격 배율은 1.0
- NPC 자신의 공격에 플레이어용 파티 합산 보너스를 중복 적용하지 않음

### 9.3 저장·UI 통합 테스트

- `loadedAmmo` 직렬화·역직렬화 왕복
- 기존 저장의 누락 필드가 0발로 마이그레이션
- 반대 슬롯 장비 교환과 부적합 장비 복구
- 전투 카드의 공격·재장전·탄약 없음 상태
- 일반 무기 카드와 상세 모달의 `N/20` 표시
- 전투 종료 후 잔탄 유지

## 10. 범위 제외
