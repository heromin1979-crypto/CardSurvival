# 제작 워크벤치 고정밀 재현 설계

## 목표

현재 제작 모달을 `제작대_샘플.png`의 정보 밀도와 시각적 위계에 가깝게 재구성한다. 기존 제작 데이터, 검색, 정렬, 상태 필터, 제작 단계 진행 기능은 유지하며 장식용 가짜 데이터는 추가하지 않는다.

## 범위

- 왼쪽 제작 목록의 행 높이, 간격, 썸네일, 상태 리본을 샘플 수준으로 압축한다.
- 중앙 스펙 시트에 카테고리별 대표 설계도 이미지를 표시한다.
- 오른쪽 제작 단계와 제작 버튼을 샘플의 대형 단계 카드 구조로 정리한다.
- 1920x1080을 기준 화면으로 삼고, 작은 화면에서는 기존 반응형 축소 규칙을 유지한다.
- 개별 아이템 전용 설계도 생성은 이번 범위에서 제외한다.

## 이미지 자산

`weapon`, `armor`, `tool`, `structure`, `food`, `medical`, `material`, `upgrade`, `consumable`의 9개 카테고리에 각각 대표 설계도 이미지를 만든다.

이미지는 어두운 제작 도면 위에서 잘 보이는 황동색과 주황색 정밀 선화로 통일한다. 배경 제거가 가능한 단색 크로마키 원본을 생성한 뒤 투명 PNG로 변환하여 `assets/images/ui/crafting-blueprints/`에 저장한다. 이미지에는 글자, 로고, 워터마크를 넣지 않으며 UI의 실제 콜아웃 텍스트와 겹치지 않도록 피사체 주변 여백을 확보한다.

선택된 청사진의 `category`를 이미지 키로 사용한다. 이미지가 없는 카테고리는 `tool` 대표 이미지를 fallback으로 사용하되, 테스트에서 현재 9개 제작 카테고리가 모두 매핑됐는지 검증한다.

## 왼쪽 목록

목록 행은 약 66px 높이, 행 간격은 3px, 썸네일은 약 42px로 축소한다. 이름과 재료 아이콘은 두 줄 안에 배치하며, 항목 높이는 긴 이름 때문에 변하지 않도록 고정한다.

제작 가능은 초록색, 재료 부족은 적색, 잠금은 무채색 상태 리본으로 구분한다. 선택 행에는 샘플과 같은 주황색 하이라이트를 사용한다. 검색, 이름/TP 정렬, 제작 가능만 보기, 상태 탭과 목록 스크롤 동작은 그대로 유지한다.

## 중앙 스펙 시트

중앙 상단은 실제 아이템명과 영문명, 희귀도를 표시한다. 대표 설계도 이미지는 중앙 프레임의 약 70% 이내로 배치하고, 재료·유형·태그·사용 슬롯을 실제 데이터에서 읽어 네 방향 콜아웃으로 표시한다.

하단 스펙, 속성, 필요 재료는 기존 계산 결과를 사용한다. 긴 텍스트는 말줄임표와 title 속성으로 처리해 레이아웃 높이를 바꾸지 않는다.

## 오른쪽 제작 단계

각 단계는 번호, 실제 단계명, 진행률, TP, 진행 막대를 표시한다. 완료 단계는 `Done`, 진행 중 단계는 `In progress`, 대기 단계는 `Ready`로 표시한다. 헤더는 모든 단계가 완료된 경우에만 `CRAFTING COMPLETE / 제작 완료`, 그 외에는 `CRAFTING STAGES / 제작 단계`를 사용한다.

제작 버튼은 기존 `CraftSystem.startBlueprint()` 경로를 유지한다. 재료나 기술 조건이 부족하면 버튼을 비활성화하고 실제 부족 사유를 표시한다.

## 구현 경계

- DOM과 데이터 결합은 `js/ui/CraftUI.js`에서 수행한다.
- 제작 모달 전용 스타일은 `css/screens-game.css`의 `.craft-workbench--spec` 범위에 둔다.
- 카테고리 이미지 경로는 `CraftUI.js`의 단일 상수 맵으로 관리한다.
- 제작 판정과 큐 진행 로직은 `CraftSystem`을 변경하지 않는다.
- 기존 아이템 카드용 `CardFactory.images`는 왼쪽 썸네일에만 사용한다.

## 검증

- `tests/integration/CraftWorkbench.int.test.js`에서 9개 이미지 매핑, 카테고리별 이미지 선택, 실제 상태 텍스트, 기존 검색·선택·제작 버튼 연결을 검증한다.
- 관련 Vitest 통합 테스트와 수정한 JavaScript 파일의 구문 검사를 실행한다.
- 1920x1080 Playwright 캡처에서 목록 행 간격, 3열 비율, 중앙 이미지 표시, 가로·세로 오버플로 부재를 확인한다.
- 최종 캡처를 샘플 이미지와 직접 비교하여 목록 밀도와 중앙 도면 크기를 조정한다.
